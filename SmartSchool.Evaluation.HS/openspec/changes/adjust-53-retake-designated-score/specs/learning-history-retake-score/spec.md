# Spec Delta

## Purpose

定義 5.3 重讀成績如何決定再次修習成績與再次修習成績及格。涵蓋產生學習歷程回寫既有資料，以及計算學期科目成績建立 5.3 的兩個再次修習分支。

## ADDED Requirements

### Requirement: 從學期科目成績讀取修課直接指定總成績
系統 MUST 從既有 5.3 對應學生、本次學年度、本次學期、相同科目與科目級別的 `sems_subj_score.score_info` 讀取 `SemesterSubjectScoreInfo/Subject` 的「修課直接指定總成績」。系統 MUST 同時讀取同一科目節點的「修課及格標準」。此讀取 MUST NOT 以補考成績存在為前提。

#### Scenario: 沒有補考成績仍讀得到指定總成績
- **WHEN** 既有 5.3 對應的科目節點有「修課直接指定總成績」，且該科目沒有補考成績
- **THEN** 系統仍取得該指定總成績與同一節點的修課及格標準

#### Scenario: 同一學期有多個相同科目與級別
- **WHEN** 同一學生、學年度、學期、科目與科目級別對到多個科目節點
- **THEN** 系統採用與既有 5.3 科目比對相同的第一筆，不另訂優先順序

### Requirement: 有效指定總成績成為再次修習成績
「修課直接指定總成績」去掉前後空白後可解析為數字時，系統 MUST 把該文字寫入既有 5.3 的再次修習成績。可解析包含 0、負數與大於 100 的數字。系統 MUST NOT 再對該值進位。補考成績存在、空白或不存在 MUST NOT 阻止這次寫入。

#### Scenario: 指定總成績優先於補考成績
- **WHEN** 指定總成績為 88，且同一科目另有補考成績
- **THEN** 該既有 5.3 的再次修習成績為 88

#### Scenario: 沒有補考成績仍寫入指定總成績
- **WHEN** 指定總成績為 0，且同一科目沒有補考成績
- **THEN** 該既有 5.3 的再次修習成績為 0

#### Scenario: 負數與超過 100 仍採用
- **WHEN** 指定總成績為 -1 或 101
- **THEN** 再次修習成績分別為 -1 或 101

### Requirement: 依修課及格標準重算再次修習成績及格
指定總成績已採用時，系統 MUST 重算再次修習成績及格。同一科目節點的修課及格標準可解析時 MUST 使用該標準，包含 0。標準不存在、空白或無法解析時 MUST 使用 60。再次修習成績大於等於標準時為 `1`，否則為 `0`。

#### Scenario: 使用科目上的及格標準
- **WHEN** 指定總成績為 59，且同一節點的修課及格標準為 60
- **THEN** 再次修習成績及格為 0

#### Scenario: 成績達到指定標準
- **WHEN** 指定總成績為 70，且修課及格標準為 70
- **THEN** 再次修習成績及格為 1

#### Scenario: 沒有有效標準時用 60
- **WHEN** 指定總成績為 60，且修課及格標準不存在、空白或不是數字
- **THEN** 再次修習成績及格為 1

#### Scenario: 標準 0 不被預設值取代
- **WHEN** 指定總成績為 0，且修課及格標準為 0
- **THEN** 再次修習成績及格為 1

### Requirement: 無效指定總成績保留原有處理
「修課直接指定總成績」不存在、空白、只有空白字元或無法解析為數字時，系統 MUST 保留該 5.3 原有的再次修習成績與再次修習成績及格，並且 MUST 保留原有的補考成績、補考及格、重讀成績與成績及格處理。

#### Scenario: 屬性空白
- **WHEN** 科目節點沒有「修課直接指定總成績」，或其值為空白
- **THEN** 再次修習成績與再次修習成績及格維持讀入時的值，補考與重讀成績處理與變更前相同

#### Scenario: 屬性不是數字
- **WHEN** 「修課直接指定總成績」為 ABC
- **THEN** 系統不採用該值，5.3 的原有成績處理維持不變

### Requirement: 重讀成績仍取三個來源的最大值
系統 MUST 保留重讀成績的最大值計算：在原有補考比對成功時，從再次修習成績、補考成績、原始成績中的可解析值取最大值。再次修習成績已改為指定總成績時，最大值 MUST 使用更新後的再次修習成績。沒有可解析值時，重讀成績 MUST 仍為空、成績及格 MUST 仍為 `-1`。沒有進入原有補考比對時，系統 MUST NOT 另算重讀成績。

#### Scenario: 最大值包含更新後的再次修習成績
- **WHEN** 指定總成績 90 已寫入再次修習成績，且原有補考比對取得補考成績 70 與原始成績 80
- **THEN** 重讀成績為 90

#### Scenario: 指定總成績較低時仍取較大值
- **WHEN** 指定總成績 50 已寫入再次修習成績，且原有補考比對取得補考成績 75 與原始成績 60
- **THEN** 重讀成績為 75

#### Scenario: 沒有補考比對時不重算重讀成績
- **WHEN** 指定總成績有效並已寫入再次修習成績，但該列沒有進入原有補考比對
- **THEN** 系統不另算重讀成績，既有重讀成績維持原值

#### Scenario: 三個來源都無法解析
- **WHEN** 原有補考比對成功，且再次修習成績、補考成績、原始成績都無法解析為數字
- **THEN** 重讀成績為空，成績及格為 -1

### Requirement: 只更新既有 5.3 且不影響其他名冊
系統 MUST 只更新本次讀到的既有 5.3 重讀成績。系統 MUST NOT 為了指定總成績建立新的 5.3。此變更 MUST NOT 改變 4.2、4.3、4.4、6.2、6.4 的成績內容、比對條件或寫入結果。

#### Scenario: 沒有既有 5.3 時不建立
- **WHEN** 學期科目有有效的修課直接指定總成績，但該學生此科目沒有既有 5.3
- **THEN** 系統不建立 5.3

#### Scenario: 其他名冊維持原結果
- **WHEN** 產生學習歷程同時處理 4.2、4.3、4.4、6.2、6.4 與 5.3
- **THEN** 前五個名冊的成績與寫入結果與套用此變更前相同

### Requirement: 計算成績的兩個再次修習分支都判斷指定總成績
計算學期科目成績建立 5.3 時，本學期科目成績已存在與尚未存在的兩個再次修習分支都 MUST 讀取相同學生、科目、科目級別的 `sc_attend.designate_final_score`。讀取 MUST 使用該分支寫入「修課直接指定總成績」的同一筆修課資料。

#### Scenario: 已存在與尚未存在的科目都套用
- **WHEN** 一筆再次修習的本學期科目成績已存在，另一筆尚未存在，且兩筆都符合原本建立 5.3 的條件
- **THEN** 兩筆 5.3 的再次修習成績與再次修習成績及格都依指定總成績規則決定

### Requirement: 有效指定總成績以既有進位寫入再次修習成績
`designate_final_score` 去掉空白後可解析為數字時，包含 0，系統 MUST 優先把進位後的值寫入 5.3.7。進位位數與方式 MUST 與該筆 `score_info`「修課直接指定總成績」相同，兩者數值 MUST 一致。補考成績存在、空白或不存在 MUST NOT 阻止採用。

#### Scenario: 指定總成績優先且與 XML 一致
- **WHEN** 指定總成績可解析，且同一筆科目會把進位結果寫入「修課直接指定總成績」
- **THEN** 5.3.7 等於該屬性的數值

#### Scenario: 指定 0 仍採用
- **WHEN** 指定總成績為 0，且沒有補考成績
- **THEN** 5.3.7 為 0 依既有位數與進位方式處理後的結果

### Requirement: 計算成績依進位後分數重算再次修習成績及格
指定總成績已採用時，5.3.8 MUST 用寫入 5.3.7 的分數比較修課及格標準。標準可解析時 MUST 使用該標準，包含 0。標準不存在、空白或無法解析時 MUST 使用 60。大於等於標準為 `1`，否則為 `0`。這段 MUST NOT 要求課程總成績存在。

#### Scenario: 沒有課程總成績仍可及格
- **WHEN** 沒有課程總成績，指定總成績進位後為 60，修課及格標準為 60
- **THEN** 5.3.7 為進位後的 60，5.3.8 為 1

#### Scenario: 低於標準
- **WHEN** 指定總成績進位後為 59，修課及格標準為 60
- **THEN** 5.3.8 為 0

#### Scenario: 標準無效時用 60
- **WHEN** 指定總成績進位後為 60，修課及格標準空白或不是數字
- **THEN** 5.3.8 為 1

#### Scenario: 標準 0 不被預設值取代
- **WHEN** 指定總成績進位後為 0，修課及格標準為 0
- **THEN** 5.3.8 為 1

### Requirement: 計算成績在指定總成績無效時保留課程成績
指定總成績不存在、空白或無法解析時，5.3.7 MUST 仍用課程最終成績的既有進位結果。5.3.8 MUST 仍依是否有課程總成績，以及未進位的課程最終成績是否達到修課及格標準來判斷。

#### Scenario: 沒有指定總成績
- **WHEN** 指定總成績不存在、空白或不是數字，且有課程總成績
- **THEN** 5.3.7 與 5.3.8 和變更前使用課程最終成績的結果相同

#### Scenario: 沒有指定總成績也沒有課程總成績
- **WHEN** 指定總成績無效，且沒有課程總成績
- **THEN** 5.3.7、5.3.8 維持原本沒有課程總成績時的處理結果

### Requirement: 計算成績不改建立條件與其他欄位
指定總成績 MUST NOT 單獨成為建立 5.3 的條件。原本的再次修習規則、先前學期或封存成績比對、不計學分限制與課程代碼檢查 MUST 保留。5.3.9 到 5.3.12、擇優與補考處理 MUST 不變。4.2、4.3、4.4、5.2、6.2、6.4 MUST 不變。同一學生、科目、級別有多筆修課時，系統 MUST 繼續使用目前字典保留的那一列，MUST NOT 在這次另定選課規則。

#### Scenario: 不符合原本建立條件
- **WHEN** 指定總成績有效，但不符合原本建立 5.3 的條件
- **THEN** 系統不因指定總成績建立 5.3

#### Scenario: 補考與重讀成績欄位不變
- **WHEN** 指定總成績有效並已寫入 5.3.7、5.3.8
- **THEN** 5.3.9 到 5.3.12 與變更前的計算結果相同

#### Scenario: 多門修課不另選課程
- **WHEN** 同一學生、科目、級別有多筆修課且指定總成績不同
- **THEN** 5.3.7 使用目前寫入「修課直接指定總成績」的那一列，不新增選課規則

### Requirement: 先計算再產生學習歷程時再次修習成績保持一致
先計算學期科目成績、再產生學習歷程時，5.3.7 MUST 維持計算時寫入的進位值。產生學習歷程 MUST 讀取該進位後的「修課直接指定總成績」，不再做第二次進位。5.3.8 MUST 依該分數與修課及格標準得到相同及格結果。

#### Scenario: 兩個功能依序執行
- **WHEN** 指定總成績有效，先執行計算學期科目成績，再執行產生學習歷程
- **THEN** 5.3.7 仍是計算時的進位值，5.3.8 與計算時的及格結果相同
