# 重讀工作表再次修習成績及格判斷方式

## 概述
重讀工作表（5.3重讀成績名冊）中的再次修習成績及格判斷是成績計算系統中的重要邏輯，主要處理學生重複修習同一科目的成績及格狀態判斷。

## 處理規則識別

### 1. 規則分類邏輯
```csharp
// 統一分類
string ruleType = "";
if (rule == "重修(寫回原學期)" || rule == "重修成績")
    ruleType = "重修成績";
else if (rule == "重讀(擇優採計成績)" || rule == "再次修習")
    ruleType = "再次修習";  // 重讀工作表的處理規則
else if (rule == "補修成績")
    ruleType = "補修成績";
```

## 再次修習成績及格判斷邏輯

### 1. 主要成績及格判斷 (ScoreP)

#### 1.1 判斷程式碼
```csharp
// 判斷是否取得學分
string ScoreP = "";
decimal passScore = 60; // 預設及格標準
if (decimal.TryParse(updateScoreElement.GetAttribute("修課及格標準"), out decimal passingStandard))
{
    passScore = passingStandard;
}
if ((sfinalScore.HasValue ? sfinalScore.Value : 0) >= passScore)
    ScoreP = "1";
else
    ScoreP = "0";
```

#### 1.2 判斷邏輯說明
- **使用成績：** `sfinalScore`（最終成績）
- **比較標準：** 修課及格標準（優先）或預設60分
- **判斷結果：**
  - 成績 >= 及格標準 → `ScoreP = "1"`（及格）
  - 成績 < 及格標準 → `ScoreP = "0"`（不及格）

### 2. 補考成績及格判斷 (ReScoreP)

#### 2.1 補考成績有效性檢查
```csharp
string reScore = "-1";
// 取得補考成績
if (decimal.TryParse(updateScoreElement.GetAttribute("補考成績"), out decimal reScoreValue2))
{
    if (decimal.TryParse(updateScoreElement.GetAttribute("修課及格標準"), out decimal passingStandard))
    {
        if (reScoreValue2 >= 0)
        {
            // 有成績，最高以修課及格標準紀錄成績
            if (reScoreValue2 > passingStandard)
                reScore = passingStandard.ToString();
            else
                reScore = reScoreValue2.ToString();
        }
        else
        {
            reScore = "-1"; // 如果無法轉數字，預設為 -1
        }
    }
    else
    {
        reScore = "-1"; // 如果無法轉數字，預設為 -1
    }
}
```

#### 2.2 補考成績及格判斷
```csharp
// 補考成績及格判斷
string reScoreP = "-1";
// 取得修課及格標準（預設 60）
string passScoreStr = updateScoreElement.GetAttribute("修課及格標準");
decimal passScore = 60;
decimal.TryParse(passScoreStr, out passScore);

if (reScore == "-1")
{
    reScoreP = "-1";
}
else if (decimal.TryParse(reScore, out decimal reScoreDecimal) && reScoreDecimal >= passScore)
{
    reScoreP = "1";
}
else
{
    reScoreP = "0";
}
```

#### 2.3 補考成績判斷邏輯說明

**第一步：補考成績有效性檢查**
- 檢查補考成績是否在 0 到修課及格標準之間
- 如果有效 → `reScore = 補考成績`
- 如果無效 → `reScore = "-1"`

**第二步：補考成績及格判斷**
- 如果 `reScore == "-1"` → `reScoreP = "-1"`（無效）
- 如果補考成績 >= 修課及格標準 → `reScoreP = "1"`（及格）
- 否則 → `reScoreP = "0"`（不及格）

## 2024年7月22日 - 修改再次修習成績及格判斷使用修課及格標準

### 修改內容
將再次修習成績及格判斷從使用固定的60分改為使用 `updateScoreElement.GetAttribute("修課及格標準")`。

### 修改位置
1. **第1133行附近** - 修改現有成績的及格判斷
2. **第1544行附近** - 修改新增成績的及格判斷

### 修改前程式碼
```csharp
// 判斷是否取得學分
string ScoreP = "";
if ((sfinalScore.HasValue ? sfinalScore.Value : 0) >= 60) // 這裡 60 可以改成你的及格標準變數
    ScoreP = "1";

    ScoreP = "0";
```

### 修改後程式碼
```csharp
// 判斷是否取得學分
string ScoreP = "";
decimal passScore = 60; // 預設及格標準
if (decimal.TryParse(updateScoreElement.GetAttribute("修課及格標準"), out decimal passingStandard))
{
    passScore = passingStandard;
}
if ((sfinalScore.HasValue ? sfinalScore.Value : 0) >= passScore)
    ScoreP = "1";
else
    ScoreP = "0";
```

### 修改說明
1. **新增變數：** 新增 `passScore` 變數來儲存及格標準
2. **預設值：** 設定預設及格標準為60分
3. **動態取得：** 使用 `decimal.TryParse` 嘗試從 `updateScoreElement.GetAttribute("修課及格標準")` 取得及格標準
4. **優先級：** 如果成功取得修課及格標準，則使用該標準；否則使用預設的60分
5. **判斷邏輯：** 使用動態取得的及格標準進行成績及格判斷

### 修改影響
1. **更準確的及格判斷：** 現在會根據每個課程的實際及格標準進行判斷，而不是使用固定的60分
2. **支援不同課程標準：** 不同課程可以設定不同的及格標準
3. **向後相容：** 如果課程沒有設定及格標準，仍會使用預設的60分
4. **一致性：** 主要成績及格判斷現在與補考成績及格判斷使用相同的及格標準來源

### 測試建議
1. 測試有設定修課及格標準的課程
2. 測試沒有設定修課及格標準的課程（應使用預設60分）
3. 測試及格標準為非60分的情況
4. 驗證重讀工作表中的成績及格狀態是否正確

## 及格判斷與「是否取得學分」欄位

### ScoreP（及格）判斷
- 只根據「修課總成績」與「修課及格標準」比較：
  - `if (sacRecord.HasFinalScore && sacRecord.FinalScore >= passScore) ScoreP = "1"; else ScoreP = "0";`
- **ScoreP 不會參考「是否取得學分」欄位。**

### 「是否取得學分」欄位
- 依據 `maxScore >= passscore` 判斷（maxScore 為該科目所有成績的最高分，passscore 為修課及格標準，預設 60）。
- 只有當 `sacRecord.NotIncludedInCredit == false` 時，才會寫入「是否取得學分」：
  - `updateScoreElement.SetAttribute("是否取得學分", maxScore >= passscore ? "是" : "否");`
- 這個欄位主要用於學分統計、畢業審查等功能。

### 關聯與差異
- **ScoreP 與「是否取得學分」邏輯獨立。**
  - ScoreP 只反映該筆成績是否及格。
  - 「是否取得學分」則反映該科目是否能計入學分，並考慮特殊情境（如不計學分）。
- 兩者數值通常一致，但在特殊情境（如不計學分）時可能不同。
