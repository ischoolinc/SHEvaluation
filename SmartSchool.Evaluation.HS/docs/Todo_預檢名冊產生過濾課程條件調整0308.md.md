## 要修改的方法
- `public DataTable GetSCAttendCourseRows(int schoolYear, int semester, List<string> studentIds)`

---

## 問題說明
目前此方法內有兩段 SQL：
1. **當 `schoolYear/semester` 等於系統預設學年期** 時使用的 SQL。
2. **當 `schoolYear/semester` 不等於系統預設學年期** 時使用的 SQL。

這兩段 SQL 目前都**沒有**加入以下課程過濾條件：

```sql
course.not_included_in_calc <> '1'
AND course.not_included_in_credit <> '1'
```

導致本來應該排除的課程，仍可能被帶入預檢名冊。

---

## 修改要求

### 1. 第一段 SQL 要補上條件
找到第一段 SQL 中 `crs_stud AS (` 內的 `WHERE`：

原本：

```sql
WHERE
    student.status IN (1, 2)
    AND course.school_year = {0}
    AND course.semester = {1}
    AND student.id IN ({2})
```

修改為：

```sql
WHERE
    student.status IN (1, 2)
    AND course.school_year = {0}
    AND course.semester = {1}
    AND student.id IN ({2})
    AND COALESCE(course.not_included_in_calc, '0') <> '1'
    AND COALESCE(course.not_included_in_credit, '0') <> '1'
```

> 注意：請使用 `COALESCE(..., '0') <> '1'`，避免欄位為 `NULL` 時造成判斷漏掉。

---

### 2. 第二段 SQL 要補上條件
找到第二段 SQL 中 `crs_stud AS (` 內的 `WHERE`：

原本：

```sql
WHERE
    student.status IN (1, 2)
    AND student.id IN ({2})
```

修改為：

```sql
WHERE
    student.status IN (1, 2)
    AND student.id IN ({2})
    AND COALESCE(course.not_included_in_calc, '0') <> '1'
    AND COALESCE(course.not_included_in_credit, '0') <> '1'
```
