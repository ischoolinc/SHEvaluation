# 匯入學期科目成績調整 0820

## 根因

`ImportSemesterSubjectScore.cs` 在匯入「修課及格標準」與「修課補考標準」時，既有 Subject 的更新路徑已正確寫入 XML，但**新增 Subject** 的兩條路徑未完整處理這兩個欄位：

1. **既有學期 + 新增科目**（`updatedNewSemesterScore`）：欄位迭代陣列未包含這兩個欄位，導致即使 `switch` 已有對應 case，也不會被迭代處理。
2. **新增學期 + 新增科目**（`insertNewSemesterScore`）：欄位迭代陣列與 `switch` 皆未包含這兩個欄位。

## 修改檔案

- `ImportExport/ImportSemesterSubjectScore.cs`

## 修改位置

| 路徑 | 行號（約） | 修改內容 |
|------|-----------|----------|
| `updatedNewSemesterScore` → 建立 `newScore` | ~754 | 欄位迭代陣列新增 `修課及格標準`、`修課補考標準` |
| `insertNewSemesterScore` → 建立 `newScore` | ~906 | 欄位迭代陣列新增 `修課及格標準`、`修課補考標準` |
| `insertNewSemesterScore` → `switch` | ~966–967 | 新增 `case "修課及格標準":`、`case "修課補考標準":` 處理 |

## 新增紀錄流程所加入的欄位

- 修課及格標準
- 修課補考標準
