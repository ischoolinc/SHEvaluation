# 期末成績單(固定排名)調整0803

## 1. 原始問題與重現條件

產生「期末成績通知單(固定排名)」時，舊版合併欄位：

```text
綜合表現：評語(含社團、競賽、服務學習、禮節等綜合表現及建議)
```

在列印第 2 學期時，有時會顯示第 1 學期文字評量內容。

重現條件：

* 同一學生第 1、第 2 學期皆有文字評量，且內容不同。
* 使用者選擇第 2 學期產生報表。
* `SemesterMoralScoreList` 中第 2 學期紀錄出現在第 1 學期之前時較易重現（先寫入第 2 學期，後被第 1 學期覆寫）。
* 少數學生抽測可能正常，大量列印（約 200 人）時較容易出現錯置。

---

## 2. 根因

學務資料「綜合表現」區塊中，上學期與本學期處理都會寫入同一組舊版欄位：

```csharp
row["綜合表現：" + face] = each.InnerText;
```

因此輸出結果會依賴 `SemesterMoralScoreList` 的紀錄順序：

* 若先處理第 2 學期、後處理第 1 學期 → 第 1 學期覆寫第 2 學期。
* 若順序相反 → 表面上看起來正確，但邏輯仍不穩定。

---

## 3. 修改檔案與位置

* 檔案：`Program.cs`
* 區塊：`#region 綜合表現`（學務資料內，約文字評量處理迴圈）

---

## 4. 實際邏輯變更

### 上學期區塊（僅在 `conf.Semester == "2"` 且處理同學年度第 1 學期時）

* **移除**對 `row["綜合表現：" + face]` 的寫入。
* 仍只寫入：
  * `上學期導師評語`
  * `上學期文字評量名稱1～10`
  * `上學期文字評量1～10`

### 本學期區塊（`info.SchoolYear` / `info.Semester` 符合使用者選擇）

* 繼續寫入：
  * `導師評語`
  * `文字評量名稱1～10`
  * `文字評量1～10`
  * `綜合表現：Face`（僅此區塊）
* 寫入前增加欄位存在檢查：

```csharp
string columnName = "綜合表現：" + face;
if (row.Table.Columns.Contains(columnName))
{
    row[columnName] = each.InnerText;
}
```

### 上限保護

文字評量迴圈改為：

```csharp
for (int i = 1; i <= faceList.Count && i <= 10; i++)
```

避免超過既有欄位 `1～10`。

---

## 5. 刻意保留的欄位與行為

未變更欄位意義與格式：

```text
導師評語
上學期導師評語
文字評量名稱1～10
文字評量1～10
上學期文字評量名稱1～10
上學期文字評量1～10
綜合表現：Face（舊版合併欄位名稱不變）
```

亦未變更：

* `SemesterMoralScoreList` 載入
* `FillSemesterMoralScore`
* 文字評量對照表驗證（`Content/Morality[@Face='...']`）
* 成績、排名、缺曠、獎懲、學分、學生基本資料
* BackgroundWorker、Word Mail Merge、報表樣板

## 6. 預期邏輯（程式審查確認）

### 選第 1 學期

```text
第 1 學期紀錄 → 導師評語 / 文字評量1～10 / 綜合表現：Face
```

### 選第 2 學期

```text
第 1 學期紀錄 → 僅上學期專用欄位（不寫綜合表現：Face）
第 2 學期紀錄 → 導師評語 / 文字評量1～10 / 綜合表現：Face
```

結果不依賴 `SemesterMoralScoreList` 順序。

## 7. 測試結果

### 程式審查（已完成）

| 案例 | 結果 |
|------|------|
| Test 1：單生第 1 學期 | 僅本學期區塊寫入 `綜合表現：Face` → 顯示第 1 學期內容 |
| Test 2：單生第 2 學期 | 上學期區塊不再寫 `綜合表現：Face` → 顯示第 2 學期內容；上學期欄位仍由第 1 學期填入 |
| Test 3：紀錄順序為 2→1 | 第 1 學期無法覆寫 `綜合表現：Face` |
| Test 4：紀錄順序為 1→2 | 本學期區塊最後（或唯一）寫入正確學期內容 |
| Test 5：第 2 學期缺少該 Face | 上學期不再寫入，故本學期欄位保持空白（不會殘留第 1 學期值） |
| Test 7：既有欄位 | 上學期／本學期專用欄位與舊版 `綜合表現：Face` 仍保留 |

### 需於正式環境／測試機手動驗證

| 案例 | 狀態 |
|------|------|
| Test 6：約 200 人批次列印 | 待實機驗證（確認每人資料獨立、無跨生錯置、分頁與 Mail Merge 正常） |
| Word 實際合併輸出抽查 | 待實機驗證（建議抽查 Test 1～5 對應學生） |

建議實機抽查合併欄位：

```text
綜合表現：評語(含社團、競賽、服務學習、禮節等綜合表現及建議)
文字評量1～10 / 上學期文字評量1～10
導師評語 / 上學期導師評語
```
