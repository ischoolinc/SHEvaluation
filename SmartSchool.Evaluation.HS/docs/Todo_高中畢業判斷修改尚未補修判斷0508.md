# Cursor Todo：修改尚未補修判斷

## 目標

修改 `GraduateEvaluator.cs` 中「尚未補修」的判斷邏輯。

目前判斷條件包含：

- 是否補修成績 = 是
- 補修學年度 = 空值
- 補修學期 = 空值

需要調整為：

- 是否補修成績 = 是
- 原始成績 = 空值

也就是：

1. 移除 `補修學年度` 判斷。
2. 移除 `補修學期` 判斷。
3. 加入 `原始成績` 空值判斷。
4. 修改完成後，記錄在 `畢業預警調整0508.md`。

---

## 修改檔案

```text
GraduateEvaluator.cs
````

---

## 修改重點

搜尋以下判斷：

```csharp
subjectScore.Detail.GetAttribute("是否補修成績") == "是"
```

找到與「尚未補修」相關的判斷區塊。

目前應該會有類似以下程式碼：

```csharp
if (subjectScore.Detail.GetAttribute("是否補修成績") == "是"
    && subjectScore.Detail.GetAttribute("補修學年度") == ""
    && subjectScore.Detail.GetAttribute("補修學期") == "")
{
    subjectElement.SetAttribute("狀態", "尚未補修");
    check.MakeupCount += credit;
}
```

需要改成：

```csharp
if (subjectScore.Detail.GetAttribute("是否補修成績") == "是"
    && subjectScore.Detail.GetAttribute("原始成績").Trim() == "")
{
    subjectElement.SetAttribute("狀態", "尚未補修");
    check.MakeupCount += credit;
}
```

---

## 建議保守改法

為了避免同一條件重複寫兩次，建議在 `if (subjectElement != null)` 裡面，`switch (check.Type)` 前面先建立共用變數。

找到類似區塊：

```csharp
if (subjectElement != null)
{
    switch (check.Type)
    {
```

改成：

```csharp
if (subjectElement != null)
{
    bool isUnMakeupScore =
        subjectScore.Detail.GetAttribute("是否補修成績") == "是"
        && subjectScore.Detail.GetAttribute("原始成績").Trim() == "";

    switch (check.Type)
    {
```

```xml
狀態="尚未補修"
```

## 驗證項目

請確認以下情境：

1. `是否補修成績 = 是` 且 `原始成績 = 空值`

   * 應寫入 `狀態="尚未補修"`。
   * 應累加 `check.MakeupCount`。

2. `是否補修成績 = 是` 且 `原始成績有值`

   * 不可寫入 `狀態="尚未補修"`。
   * 不可累加 `check.MakeupCount`。
   * 應走原本的 `已修` 或 `可重修` 流程。

3. `是否補修成績 != 是`

   * 不可寫入 `狀態="尚未補修"`。

4. 確認修改後不再使用以下欄位作為「尚未補修」判斷條件：

   * `補修學年度`
   * `補修學期`

---

## 注意事項

1. 不要修改 `已修`、`可重修`、`已取得` 的原本處理邏輯。
2. 不要移動 `check.MakeupCount += credit;` 的累加位置。
3. 不要改動其他畢業預警判斷，例如：

   * 可重修
   * 可補修文字顯示
   * 不採計
   * 非課規科目
4. 本次只調整「尚未補修」的判斷條件。
