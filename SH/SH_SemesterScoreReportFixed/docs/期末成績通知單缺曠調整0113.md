# 期末成績通知單缺曠調整 - 0113

## 修改原因
缺曠欄位在無資料時顯示空白，改為預設顯示 `0`，以符合報表需求。

## 修改位置

### 1. 建立缺曠欄位清單（約第 153-156 行）
- 在 `Program_Click` 方法中，新增 `absenceColumnNames` 清單用於追蹤所有缺曠欄位名稱
- 在建立 DataTable 欄位時同步收集缺曠欄位名稱：
  - 第 561-566 行：收集「前學期」「本學期」「學年」+ 缺曠類型的欄位
  - 第 929-940 行：收集動態產生的缺曠欄位（期間類型 + 缺曠類型）

### 2. 新增初始化方法（約第 88-100 行）
- 新增 `InitAbsenceDefault` 私有靜態方法
- 功能：將指定 DataRow 的所有缺曠欄位初始化為 "0"
- 包含防呆機制：檢查欄位是否存在才設定，避免未來欄位調整造成例外

### 3. 在建立 DataRow 時初始化（約第 1304-1307 行）
- 在 `foreach (var stuRec in studentRecords)` 迴圈中
- 於 `DataRow row = table.NewRow();` 之後立即呼叫 `InitAbsenceDefault(row, absenceColumnNames)`
- 確保缺曠欄位在填入其他資料前已預設為 "0"

### 4. 修改缺曠填入邏輯（約第 1338-1391 行）
- 將原本的 `ContainsKey` + `Keys.Contains` 改為使用 `TryGetValue`
- 只在缺曠統計字典中有實際值時才覆寫欄位
- 修改三個區塊：
  - 學年缺曠（AttendanceCountDict）
  - 前學期缺曠（AttendanceCountDict1）
  - 本學期缺曠（AttendanceCountDict2）

## 採用的作法

1. **建立缺曠欄位清單**：在建立 DataTable 欄位時同步收集所有缺曠欄位名稱至 `absenceColumnNames` 清單
2. **早期初始化**：在每位學生建立 DataRow 後，立即呼叫 `InitAbsenceDefault` 將所有缺曠欄位設為 "0"
3. **有值才覆寫**：使用 `TryGetValue` 檢查缺曠統計字典，只在有實際值時才覆寫欄位
4. **防呆機制**：初始化方法中包含欄位存在性檢查，避免未來欄位調整造成執行期例外

## 注意事項

1. 缺曠欄位清單必須和 DataTable 欄位同步（新增欄位時就收集）
2. 初始化方法包含 `Columns.Contains` 防呆，避免未來有人拔掉欄位造成執行期例外
3. 覆寫缺曠時使用 `TryGetValue`，避免查不到 key 時拋例外
4. 不影響既有功能判斷與資料流（欄位有無、合併欄位名稱、其他數值/文字欄位、排名/五標/區間等）
