# 匯入重補修成績調整 1006

## 修改日期

2026-10-06

## 修改檔案

- `ImportExport/ImportMakeupRetakeScore.cs`

## 問題原因

`ValidateRow` 只對 `e.SelectFields` 裡的欄位做內容驗證。Excel 若完全沒有某個必填欄位，該欄位不會進入 `switch`，缺少欄位就不會被擋下。

`ValidateStartEventArgs` 只有學生編號清單，沒有匯入欄位，因此無法在 `ValidateStart` 檢查 Excel 欄位是否存在。

## RequiredFields 調整內容

`requiredImportFields` 與 `wizard.RequiredFields` 使用同一份清單。選取匯入欄位時，這些欄位不可取消。自動判斷與手動判斷取得學分都不會把「成績年級」或「取得學分」移出必填。

- 科目
- 科目級別
- 學年度
- 學期
- 成績年級
- 是否補修成績
- 補修學年度
- 補修學期
- 重修學年度
- 重修學期
- 學分數
- 分項類別
- 必選修
- 校部訂
- 原始成績
- 重修成績
- 取得學分

## Excel 欄位存在檢查方式

在 `ValidateRow` 逐欄內容驗證之前，先確認 `requiredImportFields` 全部都在 `e.SelectFields`。

缺少欄位時：

- 立即結束該列驗證，不進入原本的內容與成績處理。
- 錯誤訊息為「缺少必填欄位：」加上欄位名稱。同一列缺少多個欄位時，逐一列出。
- 使用 `HashSet<string>` 記錄已回報的欄位。同一輪驗證裡，同一個缺少欄位只回報一次，避免每一列重複累加。
- `ValidateStart` 會清空這個集合，下一輪驗證可重新檢查。

有任一列帶有此錯誤時，匯入精靈不會完成匯入。

## ValidateStart / ValidateRow 實作位置

| 位置 | 作用 |
|------|------|
| `ValidateStart` | 清空已回報的缺少欄位紀錄，並沿用原本的學生成績載入。這裡拿不到匯入欄位清單。 |
| `ValidateRow` 開頭 | 檢查必填欄位是否存在於本次匯入欄位。 |
| `ValidateRow` 原內容驗證 | 欄位都存在後，繼續檢查空白、數值與允許值。 |

## 必填值驗證方式

欄位存在之後，仍走原本的列內容驗證。

| 欄位 | 空白 | 內容錯誤 |
|------|------|----------|
| 學分數 | 必須填寫 | 必須填入數字或小數 |
| 分項類別 | 必須填寫 | 必須填入 學業、專業科目或實習科目（僅允許學業、專業科目、實習科目） |
| 必選修 | 必須填寫 | 必須填入必修或選修 |
| 校部訂 | 必須填寫 | 必須填入校訂或部定（允許校訂、部訂、部定） |
| 原始成績 | 必須填寫 | 必須填入數值 |
| 重修成績 | 必須填寫 | 必須填入數值 |
| 取得學分 | 必須填寫 | 自動判斷必須為「自動」；手動判斷必須為「是」或「否」 |

學年度，以及補考成績、手動調整成績、學年調整成績、修課及格標準、修課補考標準、修課直接指定總成績，仍沿用原本驗證。

本次未改動重修成績擇優、補修成績處理、取得學分自動計算、修課及格標準、補修 4.3 名冊、重修 5.2 名冊、學期科目成績更新，以及其他非必填欄位的驗證。

## 測試案例與結果

專案 Debug 組建成功。另以測試程式呼叫實際的 `InitializeImport` 與 `ValidateRow`，結果如下。

| 項目 | 結果 |
|------|------|
| 初始、手動、自動三種狀態下，上述 17 個欄位皆在 RequiredFields | 通過 |
| Excel 匯入欄位缺少「重修成績」 | 第一列失敗，訊息「缺少必填欄位：重修成績」；下一列不重複同一訊息 |
| Excel 匯入欄位缺少「原始成績」 | 第一列失敗，訊息「缺少必填欄位：原始成績」；下一列不重複 |
| Excel 匯入欄位缺少「學分數」 | 第一列失敗，訊息「缺少必填欄位：學分數」；下一列不重複 |
| 同一列同時缺少「原始成績」與「重修成績」 | 第一列同時列出兩個缺少欄位；下一列不重複 |
| 重修成績欄位存在但資料空白 | 該列失敗，訊息「必須填寫」 |
| 學分數 = ABC | 失敗，訊息「必須填入數字或小數」 |
| 自動判斷，取得學分 = 自動 | 通過欄位存在檢查，並通過格式驗證 |
| 手動判斷，取得學分 = 是或否 | 通過欄位存在檢查，並通過格式驗證 |
| 原始成績空白、非數值；重修成績非數值 | 失敗，沿用原本訊息 |
| 分項類別空白；必選修、校部訂內容不在允許值 | 失敗，沿用原本訊息 |
| 補考成績空白 | 仍允許 |

匯入精靈畫面本身未在校務系統內操作。必填欄位、缺少欄位與列驗證是對編譯後的匯入程式直接呼叫。
