# 學期成績學年度調整程式分析報告

## 程式概述
**檔案名稱**: `SemesterScoreDataTransfer.cs`  
**命名空間**: `SmartSchool.Evaluation.Content.ChangeSchoolYear`  
**主要功能**: 處理學期成績資料的學年度調整、轉移和資料管理

## 類別結構
### 主要類別: `SemesterScoreDataTransfer`

## 核心功能分析

### 1. 學年度調整功能
#### `CheckAndUpdateStudentSemesterScoreSchoolYear()`
- **功能**: 檢查並更新學生學期分項成績學年度
- **參數**: 
  - `sourceData`: 來源成績資料
  - `ChangeSchoolYear`: 目標學年度
- **邏輯流程**:
  1. 檢查目標學年度是否已有資料
  2. 如果沒有資料，則更新原資料的學年度
  3. 使用 SQL UPDATE 語句修改 `sems_entry_score` 表
- **回傳值**: 更新後的記錄ID，失敗時回傳-1

#### `UpdateStudentSemesterScoreSchoolYearBySemsID()`
- **功能**: 透過學期成績ID更新學年度
- **參數**: 
  - `SemsScoreID`: 學期成績ID
  - `SchoolYear`: 新學年度
- **操作**: 更新 `sems_subj_score` 表的學年度欄位

### 2. 資料操作功能
#### `InsertData()`
- **功能**: 新增成績資料到 `sems_subj_score` 表
- **欄位**: 學生ID、學年度、學期、年級、成績資訊
- **回傳值**: 新增記錄的ID

#### `GetStudentScoreDataByIDSchoolYear()`
- **功能**: 依學生ID、學年度、學期查詢成績資料
- **查詢條件**: 學生ID、學年度、學期
- **回傳**: 包含成績資訊的 `SemesterScoreData` 物件

#### `UpdateScoreDataBySemesScoreID()`
- **功能**: 透過學期成績ID更新成績資料
- **更新欄位**: 成績資訊 (`score_info`)

#### `DeleteSemesScoreBySemsID()`
- **功能**: 刪除指定的學期成績記錄
- **回傳值**: 被刪除記錄的ID

### 3. 成績資料比對與合併
#### `CheckHasSubjectNameLevel()`
- **功能**: 比對兩個成績資料中科目名稱與級別的相同性
- **比對邏輯**: 
  - 使用 "科目名稱_科目級別" 作為唯一鍵值
  - 解析 XML 格式的成績資訊
  - 回傳相同的科目資訊列表
- **特殊處理**: 將 "部訂" 統一為 "部定"

#### `AppendScoreData()`
- **功能**: 將來源成績資料附加到目標成績資料
- **處理方式**: 
  - 解析 XML 格式的成績資訊
  - 將來源的科目資料合併到目標資料中
  - 回傳合併後的 XML 字串

### 4. 查詢功能
#### `GetStudentHasSemsScoreSchoolYearSemesterByID()`
- **功能**: 取得學生目前有成績的學年度、學期、年級資訊
- **回傳格式**: Dictionary<string, string>
  - Key: "學年度_學期"
  - Value: 年級
- **資料來源**: `sems_subj_score` 表

## 資料庫結構
### 主要資料表
1. **`sems_entry_score`**: 學期分項成績表
   - 欄位: id, ref_student_id, school_year, semester
   
2. **`sems_subj_score`**: 學期科目成績表
   - 欄位: id, ref_student_id, school_year, semester, grade_year, score_info

## 技術特點
1. **XML 資料處理**: 使用 `XElement` 解析和操作 XML 格式的成績資訊
2. **SQL 查詢**: 使用 `QueryHelper` 進行資料庫操作
3. **錯誤處理**: 使用 try-catch 包裝所有資料庫操作
4. **回傳值設計**: 統一使用整數回傳值，-1 表示操作失敗

## 使用場景
1. **學年度調整**: 當學校需要調整學年度時，將學生成績資料轉移到新的學年度
2. **成績資料管理**: 新增、更新、刪除學期成績記錄
3. **成績資料合併**: 將不同來源的成績資料合併
4. **資料完整性檢查**: 檢查成績資料的科目重複性

## 注意事項
1. **資料一致性**: 更新學年度時需要確保目標學年度沒有重複資料
2. **XML 格式**: 成績資訊使用 XML 格式儲存，需要正確的 XML 解析
3. **錯誤處理**: 所有資料庫操作都有異常處理，但僅輸出到 Console
4. **回傳值檢查**: 使用前需要檢查回傳值是否為 -1（失敗）

## 建議改進
1. **日誌記錄**: 建議使用正式的日誌系統替代 Console.WriteLine
2. **參數驗證**: 增加輸入參數的驗證邏輯
3. **交易處理**: 考慮使用資料庫交易確保資料一致性
4. **效能優化**: 大量資料處理時可考慮批次操作

##### 步驟1: 檢查目標學年度是否已有資料
```csharp
string query1 = string.Format(@"
    SELECT
        id
    FROM
        sems_entry_score
    WHERE
        ref_student_id = {0}
        AND school_year = {1}
        AND semester = {2}
```

- **查詢條件**: 學生ID + 目標學年度 + 學期
- **回傳**: 如果沒有資料 (`dt.Rows.Count == 0`)，則可以進行資料搬移

##### 步驟2: 取得來源分項成績ID

- **重要性**: 這個ID是用來更新學年度的關鍵
