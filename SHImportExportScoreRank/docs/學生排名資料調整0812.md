## 4. 查詢條件

`GetStudentRankDetail` 使用條件：

```text
ref_student_id  = UC 傳入 StudentId
school_year       = UC 傳入 SchoolYear
semester          = -1
item_type         = 學年/分項成績
ref_exam_id       = -1
extension_name    = 排名資料
成績類型          = UC 傳入 ScoreType
成績項目          = UC 傳入 ScoreItem
```

與清單查詢不同：明細查詢**不**限制 `rank_type`，以便同一學年度／成績類型／成績項目下，顯示所有排名範圍（班排、科排、年排等，若資料庫存在）。

沿用 `RankOverrideDataAccess` 既有方式：

```sql

    jsonb_array_elements(

```

| 鍵值 | 用途 |

## 10. RankDisplay 排名顯示調整（0812）

### 修改目標

調整學生排名資料的排名顯示方式，讓 DataGrid「排名」欄位依 `Rank` 與 `MatrixCount` 正確組合顯示。

### 修改檔案

| 檔案 | 說明 |
|---|---|
| `DAO\StudentRankDetailData.cs` | 調整 `StudentRankDetailItem.RankDisplay` 顯示規則 |

未修改：

- `rank_override` Schema
- 學年分項排名 Excel 匯入欄位
- `UpsertSchoolYearEntryRanks()`
- extension JSON 結構
- `RankOverrideDataAccess.GetStudentRankDetail()` SQL
- `frmStudentRankDetail` DataGrid 欄位綁定（仍為 `RankDisplay`）
- 其他排名計算邏輯

### 修改前問題

原本 `RankDisplay` 在只有 `Rank`、沒有 `MatrixCount` 時，無法正確顯示排名（例如學年分項排名匯入資料僅有 `rank`、無 `matrix_count` 時，畫面可能顯示空白）。

### 修改後規則

```text
Rank 有值 + MatrixCount 無值 → 顯示 Rank（例如 15）
Rank 有值 + MatrixCount 有值 → 顯示 Rank / MatrixCount（例如 15 / 25）
Rank 無值 → 顯示空白（不論 MatrixCount 是否有值）
```

### 實作

`StudentRankDetailItem.RankDisplay`：

```csharp
public string RankDisplay
{
    get
    {
        if (!Rank.HasValue)
            return string.Empty;

        if (!MatrixCount.HasValue)
            return Rank.Value.ToString();

        return Rank.Value + " / " + MatrixCount.Value;
    }
}
```

### 測試結果

| 案例 | Rank | MatrixCount | 預期 RankDisplay | 結果 |
|---|---:|---:|---|---|
| 只有排名（學年分項排名） | 5 | null | `5` | 通過（邏輯驗證） |
| 排名 + 排名母數 | 5 | 30 | `5 / 30` | 通過（邏輯驗證） |
| 兩者皆空 | null | null | 空白 | 通過（邏輯驗證） |
| Rank 空白但 MatrixCount 有值 | null | 30 | 空白 | 通過（邏輯驗證） |
| 既有排名資料 | 15 | 25 | `15 / 25` | 通過（邏輯驗證） |
| 專案 Build | — | — | 無 Compiler Error | 通過 |

## 11. matrix_count 安全解析調整（0812）

### 修改原因

`frmStudentRankDetail` 讀取排名資料時，需要允許 `matrix_count` 沒有資料。當 `matrix_count` 為空字串、空白字串或無法解析的內容時，原本 `ToNullableInt()` 使用 `Convert.ToInt32()` 會拋出 `FormatException`（「輸入字串格式不正確」），導致整個學生排名明細無法載入。

學年分項排名匯入不一定提供 `matrix_count`，因此 `rank` 有值、`matrix_count` 為 NULL 是合法資料，不應中斷讀取。

### 修改檔案

| 檔案 | 說明 |
|---|---|
| `DAO\RankOverrideDataAccess.cs` | 調整 `ToNullableInt()` 為安全解析 |

未修改：

- `rank_override` Schema
- 不新增 `matrix_count` DB 欄位
- 學年分項排名 Excel 匯入格式
- `UpsertSchoolYearEntryRanks()` 寫入邏輯
- extension JSON 結構
- `StudentRankDetailItem.RankDisplay`（已符合顯示規則，無需重複修改）
- `frmStudentRankDetail` DataGrid 欄位綁定（仍為 `RankDisplay`）
- 其他排名功能

### 修改內容

`ToNullableInt()` 改為使用 `int.TryParse` 安全解析：

```csharp
private static int? ToNullableInt(object value)
{
    if (value == null || value == DBNull.Value)
        return null;

    string text = Convert.ToString(value);

    if (string.IsNullOrWhiteSpace(text))
        return null;

    int result;
    if (int.TryParse(text.Trim(), out result))
        return result;

    return null;
}
```

`MapDetailItem` 中 `MatrixCount = ToNullableInt(row["matrix_count"])` 維持不變，但因 `ToNullableInt` 已安全化，以下情況皆回傳 `null` 而不拋出 Exception：

```text
NULL、DBNull.Value、空字串、空白字串、無法解析的內容（如 abc）
```

### 最終顯示規則

沿用 `StudentRankDetailItem.RankDisplay`：

```text
Rank 有值 + MatrixCount 無值 → 顯示 Rank（例如 3）
Rank 有值 + MatrixCount 有值 → 顯示 Rank / MatrixCount（例如 3 / 25）
Rank 無值 → 顯示空白（不論 MatrixCount 是否有值）
```

### 測試結果

| 案例 | rank | matrix_count | 預期 MatrixCount | 預期 RankDisplay | 結果 |
|---|---:|---|---|---|---|
| 只有排名（學年分項排名） | 2 | NULL | null | `2` | 通過（邏輯驗證） |
| 排名 + 排名母數 | 2 | 30 | 30 | `2 / 30` | 通過（邏輯驗證） |
| 兩者皆 NULL | null | null | null | 空白 | 通過（邏輯驗證） |
| matrix_count 空字串 | 2 | `""` | null | `2` | 通過（邏輯驗證） |
| matrix_count 空白 | 2 | `" "` | null | `2` | 通過（邏輯驗證） |
| 非法 matrix_count | 2 | `abc` | null | `2` | 通過（邏輯驗證） |
| 無排名但有母數 | null | 25 | 25 | 空白 | 通過（邏輯驗證） |
| 既有排名資料 | 15 | 25 | 25 | `15 / 25` | 通過（邏輯驗證） |
| 專案 Build | — | — | — | 無 Compiler Error | 通過 |
