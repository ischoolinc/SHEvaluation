# Todo｜新增「含不評分課程」調整（1226）

## 目標
1. 依 UI 勾選 **chkNotIncludedInCalc（含不評分課程）** 控制清單顯示：
   - 預設 **未勾選**：僅顯示 `not_included_in_calc = '0'`（列入計算）的課程
   - 勾選：顯示全部課程（含不評分）

3. 移除 QueryData.cs 中以 SQL `not_included_in_calc='0'` 直接過濾的作法，改由 C# 物件屬性篩選。

## Todo 1｜擴充 DAO：CourseScoreBase 加入不評分屬性
### 檔案
- `CourseScoreBase.cs`

### 修改
在 `CourseScoreBase` 類別新增欄位：

```csharp
/// <summary>
/// 是否不列入成績計算（不評分課程）
/// true = 不列入計算
/// false = 列入計算
/// 規則：只有 not_included_in_calc == "0" 才為 false，其餘皆為 true
/// </summary>
public bool NotIncludedInCalc { get; set; }

/// <summary>
/// DB 原始 not_included_in_calc 值（除錯用）
/// </summary>
public string NotIncludedInCalcRaw { get; set; }
```

## Todo 2｜QueryData：主查詢改為「帶出 not_included_in_calc，不在 SQL 過濾」
### 檔案
- `QueryData.cs`

### 修改 2.1：GetCourseScoreBaseByCourseSchoolYearSemester()
1. **SQL SELECT 增加欄位** `course.not_included_in_calc`
2. **SQL WHERE 移除** `and not_included_in_calc='0'`

範例（請依原字串拼接方式調整）：

```sql
select course.id, course.course_name, course.not_included_in_calc
from course
where course.school_year = {SchoolYear}
  and course.semester = {Semester}
order by course.course_name, course.id;
```

3. 在組 `CourseScoreBase` 時，寫入 `NotIncludedInCalcRaw` 與 `NotIncludedInCalc`：

```csharp
string raw = dr["not_included_in_calc"] == DBNull.Value ? null : dr["not_included_in_calc"].ToString();
csb.NotIncludedInCalcRaw = raw;

// 定案規則：只有 "0" 才是 false，其他一律 true
csb.NotIncludedInCalc = raw != "0";
```

### 修改 2.2：GetCousreTempleScoreTypeBySchoolYearSemester()
1. **SQL WHERE 移除** `not_included_in_calc='0'`
2. 其餘條件（school_year / semester）保留

> 原因：若不移除，當 UI 顯示不評分課程時，這些課程的 ScoreSource 可能永遠查不到而顯示空白。

### 驗收
- 不勾「含不評分課程」時：UI 仍只看到列入計算課程（待 Todo 3）
- 勾選後：不評分課程出現且 ScoreSource（若有模板）可正常呈現
