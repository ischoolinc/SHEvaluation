# 期末成績通知單調整 - 程式碼解析

## 程式碼位置
`Program.cs` 第21-34行

## 程式碼功能概述
這段程式碼主要負責設定期末成績通知單功能按鈕的權限控制和事件處理。

## 詳細程式碼解析

### 1. 按鈕初始化與權限控制
```csharp
var btn = K12.Presentation.NLDPanels.Student.RibbonBarItems["資料統計"]["報表"]["成績相關報表"]["期末成績通知單"];
btn.Enable = false;
```
- 從學生面板的選單中取得「期末成績通知單」按鈕
- 初始狀態設為禁用（`Enable = false`）

### 2. 動態權限控制
```csharp
K12.Presentation.NLDPanels.Student.SelectedSourceChanged += delegate
{
    btn.Enable = Permissions.期末成績通知單權限 && (K12.Presentation.NLDPanels.Student.SelectedSource.Count > 0);
};
```
- 監聽學生選擇來源變更事件
- 按鈕啟用條件：
  - 使用者具有「期末成績通知單」權限
  - 已選擇學生（選擇數量 > 0）

### 3. 按鈕點擊事件
```csharp
btn.Click += new EventHandler(Program_Click);
```
- 為按鈕添加點擊事件處理器
- 點擊時會執行 `Program_Click` 方法

### 4. 權限設定
```csharp
Catalog permission = RoleAclSource.Instance["學生"]["功能按鈕"];
permission.Add(new RibbonFeature(Permissions.期末成績通知單, "期末成績通知單"));
```
- 取得學生功能按鈕的權限目錄
- 添加「期末成績通知單」功能權限

## 重要概念說明

### K12.Presentation.NLDPanels.Student
- 代表學生面板的選單介面
- 提供學生相關功能的選單項目

### 權限控制機制
- 使用 `Permissions.期末成績通知單權限` 檢查使用者權限
- 結合選擇狀態進行動態權限控制

### 事件驅動設計
- 使用委派（delegate）處理選單狀態變更
- 實現響應式的使用者介面控制

## 程式碼特點
1. **安全性**：雙重權限檢查（功能權限 + 選擇狀態）
2. **使用者體驗**：動態啟用/禁用按鈕
3. **模組化**：權限和事件處理分離
4. **可維護性**：清晰的程式碼結構和命名

## 相關檔案
- `Permissions.cs`：權限常數定義
- `Program.cs`：主要程式邏輯
