# 學習歷程調整 - 程式功能解析

## StudentLearningHistoryProcessor.cs 功能解析

### 檔案位置
`Process/Wizards/LearningHistory/StudentLearningHistoryProcessor.cs`

### 主要功能概述
`StudentLearningHistoryProcessor` 是學習歷程資料處理的核心類別，負責將學生的學期科目成績轉換為符合108課綱學習歷程檔案格式的資料。

### 核心方法

#### ProcessLearningHistory()
**主要處理流程：**

1. **資料初始化**
   - 設定學年度學期參數
   - 建立各種成績記錄清單
   - 初始化學生資料字典

2. **學生資料分組**
   - 依年級分批處理學生資料
   - 建立班級學生對照字典
   - 取得學生畢業年級對照

3. **異動學生處理**
   - 取得異動代碼對照表
   - 識別有異動記錄的學生
   - 處理轉學轉科等特殊情況

4. **成績資料取得**
   - 分批取得學生學期科目成績
   - 處理一般成績與補修成績
   - 取得學期對照歷史資料

5. **修課設定處理**
   - 取得修課設定再次修習規則
   - 處理重複科目級別的計算方式
   - 統一分類處理規則

6. **成績資料轉換**
   - 將XML格式成績轉換為108課綱格式
   - 處理各種成績類型（一般、補修、重修、重讀）
   - 計算及格狀態與學分採計

7. **資料驗證與儲存**
   - 驗證成績資料完整性
   - 寫入各種成績類型到資料庫

### 重要資料結構


### 4.3 補修工作頁處理功能

#### 新增方法：GetScores43()
**檔案位置：** `Process/Wizards/LearningHistory/LearningHistoryDataAccess.cs`

**功能說明：**
- 使用傳入的 SchoolYear, Semester, StudentID 取得學習歷程 4.3 補修資料
- 支援單一學生或全部學生資料查詢
- 自動驗證資料完整性

**方法簽名：**
```csharp
public List<SubjectScoreRec108> GetScores43(int SchoolYear, int Semester, List<string> StudentIDList = null)
```

**參數說明：**
- `SchoolYear` (int): 學年度
- `Semester` (int): 學期  
- `StudentIDList` (List<string>): 學生ID列表，可為null表示取得所有學生

**回傳值：**
- `List<SubjectScoreRec108>`: 補修成績資料列表

**主要功能：**

1. **資料庫查詢**
   ```sql
   SELECT 
       j_subject_info.ref_student_id,
       j_subject_info.school_year,
       j_subject_info.semester,
       j_subject_info.subject,
       j_subject_info.subject_level,
       j_subject_detail.serial_no,
       j_subject_detail.name,
       j_subject_detail.value
   FROM j_subject_info 
   LEFT JOIN j_subject_detail ON j_subject_info.id = j_subject_detail.ref_j_subject_info_id
   WHERE j_subject_info.serial_no = '4.3'
       AND j_subject_info.school_year = {SchoolYear}
       AND j_subject_info.semester = {Semester}
       AND ref_student_id IN ({studentIDs})
   ```

2. **資料對應處理**
   - 將資料庫查詢結果對應到 `SubjectScoreRec108` 物件
   - 處理所有 4.3 相關欄位 (4.3.1 ~ 4.3.23)
   - 自動設定 `isScScore = true` 標記為補修成績

3. **資料驗證**
   - 檢查身分證號碼是否填寫
   - 檢查課程代碼是否填寫
   - 設定 `checkPass` 標記

4. **錯誤處理**
   - 使用 try-catch 包裝資料庫操作
   - 記錄錯誤日誌到 FISCA.LogAgent

**使用範例：**
```csharp
// 取得特定學生的4.3補修資料
var learningHistoryDataAccess = new LearningHistoryDataAccess();
var studentIDs = new List<string> { "學生ID1", "學生ID2", "學生ID3" };
var scores = learningHistoryDataAccess.GetScores43(110, 1, studentIDs);

// 取得所有學生的4.3補修資料
var allScores = learningHistoryDataAccess.GetScores43(110, 1);

// 取得單一學生的4.3補修資料
var singleStudentScores = learningHistoryDataAccess.GetScores43(110, 1, new List<string> { "學生ID" });
```

**對應的4.3欄位：**
- 4.3.1: 身分證號 → `ssr.IDNumber`
- 4.3.2: 出生日期 → `ssr.Birthday`
- 4.3.3: 應修課學年度 → `ssr.SchoolYear`
- 4.3.4: 應修課學期 → `ssr.Semester`
- 4.3.5: 課程代碼 → `ssr.CourseCode`
- 4.3.6: 科目名稱 → `ssr.SubjectName`
- 4.3.7: 開課年級 → `ssr.GradeYear`
- 4.3.8: 修課學分 → `ssr.Credit`
- 4.3.9: 補修成績 → `ssr.Score`
- 4.3.10: 補修及格 → `ssr.ScoreP`
- 4.3.11: 補考成績 → `ssr.ReScore`
- 4.3.12: 補考及格 → `ssr.ReScoreP`
- 4.3.13: 補修方式 → `ssr.ScScoreType`
- 4.3.14: 是否採計學分 → `ssr.useCredit`
- 4.3.15: 質性文字描述 → `ssr.Text`
- 4.3.17: 備註(學生姓名) → `ssr.Name`
- 4.3.18: 備註(資料當學期班級) → `ssr.HisClassName`
- 4.3.19: 備註(資料當學期座號) → `ssr.HisSeatNo`
- 4.3.20: 備註(資料當學期學號) → `ssr.HisStudentNumber`
- 4.3.21: 備註(資料次學期班級) → `ssr.ClassName`
- 4.3.22: 備註(資料次學期座號) → `ssr.SeatNo`
- 4.3.23: 備註(資料次學期學號) → `ssr.StudentNumber`

#### 新增寫入資料庫方法

##### GetAndSaveScores43()
**功能說明：**
- 取得4.3補修成績資料並寫入資料庫
- 結合查詢和寫入功能，提供一站式服務

**方法簽名：**
```csharp
public List<SubjectScoreRec108> GetAndSaveScores43(int SchoolYear, int Semester, List<string> StudentIDList = null, bool saveToDatabase = true)
```

**參數說明：**
- `SchoolYear` (int): 學年度
- `Semester` (int): 學期
- `StudentIDList` (List<string>): 學生ID列表，可為null表示取得所有學生
- `saveToDatabase` (bool): 是否寫入資料庫，預設為true

**使用範例：**
```csharp
// 取得資料並寫入資料庫
var learningHistoryDataAccess = new LearningHistoryDataAccess();
var studentIDs = new List<string> { "學生ID1", "學生ID2" };
var scores = learningHistoryDataAccess.GetAndSaveScores43(110, 1, studentIDs);

// 只取得資料，不寫入資料庫
var scoresOnly = learningHistoryDataAccess.GetAndSaveScores43(110, 1, studentIDs, false);
```

##### UpdateScores43()
**功能說明：**
- 更新4.3補修成績資料（先刪除舊資料再寫入新資料）
- 支援部分學生或全部學生的資料更新
- 提供完整的錯誤處理和日誌記錄

**方法簽名：**
```csharp
public bool UpdateScores43(int SchoolYear, int Semester, List<string> StudentIDList = null, List<SubjectScoreRec108> scores = null)
```

**參數說明：**
- `SchoolYear` (int): 學年度
- `Semester` (int): 學期
- `StudentIDList` (List<string>): 學生ID列表，可為null表示處理所有學生
- `scores` (List<SubjectScoreRec108>): 要寫入的成績資料，可為null表示重新取得資料

**回傳值：**
- `bool`: 是否成功更新

**使用範例：**
```csharp
// 更新特定學生的資料
var learningHistoryDataAccess = new LearningHistoryDataAccess();
var studentIDs = new List<string> { "學生ID1", "學生ID2" };
bool success = learningHistoryDataAccess.UpdateScores43(110, 1, studentIDs);

// 更新所有學生的資料
bool success = learningHistoryDataAccess.UpdateScores43(110, 1);

// 使用自訂資料更新
var customScores = new List<SubjectScoreRec108>();
// ... 設定自訂資料 ...
bool success = learningHistoryDataAccess.UpdateScores43(110, 1, studentIDs, customScores);
```

**主要特色：**
1. **資料完整性：** 先刪除舊資料再寫入新資料，確保資料一致性
2. **彈性操作：** 支援部分學生或全部學生的資料更新
3. **錯誤處理：** 完整的try-catch錯誤處理機制
4. **日誌記錄：** 詳細的操作日誌記錄，包含成功和錯誤資訊
5. **效能優化：** 使用SQL批量操作，提高資料庫操作效率

**資料庫操作流程：**
1. 刪除 `j_subject_detail` 中的舊資料
2. 刪除 `j_subject_info` 中的舊資料
3. 重新取得或使用傳入的成績資料
4. 使用 `SaveScores43` 寫入新資料
5. 記錄操作日誌

- **6.3.9** - 第一次及格 (ssr.ScoreP)
- **6.3.11** - 第二次及格 (固定值 "-1")

> **補充：6.3.9 第一次及格（ScoreP）判斷邏輯**
> - ScoreP 會以 ReScore（第一次補考成績）與「上、下學期修課及格標準」的最低分比較。
> - 若 ReScore >= min(PassStandard1, PassStandard2) 則 ScoreP = "1"（及格），否則 ScoreP = "0"（不及格）。
> - 若 ReScore 或及格標準無法比較，則 ScoreP = "-1"。

### 6.4 轉學轉科成績 (SaveScores64)
- **6.4.11** - 成績及格 (ssr.ScoreP)
