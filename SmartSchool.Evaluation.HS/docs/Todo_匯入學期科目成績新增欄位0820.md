# Goal

Fix `ImportSemesterSubjectScore.cs` so that when a new semester subject score record is created, the following two fields are correctly written into the Subject XML:

* 修課及格標準
* 修課補考標準

Do not change any other existing logic.

# Target File

* `ImportSemesterSubjectScore.cs`

# Problem

The importer already supports these two fields in:

* `wizard.ImportableFields`
* input validation
* updating an existing Subject record

However, when creating a new Subject record, these two fields are not always added to the generated `<Subject>` XML.

There are two new-record paths that must be checked and fixed.

# Required Changes

## 1. Existing semester, adding a new Subject

Locate the code that handles:

```csharp

```

```csharp

```

The current field iteration list does not include:

```text

```

Add only these two fields to the existing field list.

The existing `switch` in this section already contains handling for:

```csharp

```

```xml

```
