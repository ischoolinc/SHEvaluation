## 6. 必要欄位及驗證規則

### 必要欄位

```text
學號、班級、姓名、學年度、年級、學年學業排名
```

### 允許空白

```text
座號、科別
```

### 驗證摘要

| 欄位 | 規則 |
|---|---|
| 學號 | 不可空白；系統須存在；不可對應多位學生 |
| 班級 | 不可空白；Trim 後寫入 `rank_name` |
| 姓名 | 不可空白；Trim 後須與系統姓名一致 |
| 學年度 | 整數 1～3000 |
| 年級 | 整數 1～9 |
| 學年學業排名 | 整數且 > 0 |
| 座號 | 可空白；有值時須為整數 |
| 科別 | 可空白；僅辨識用 |
| 檔內重複 | 同一檔案「學號＋學年度」不可重複 |

自訂驗證器 Type：`SHIMPORTEXPORTSCORERANKCHECKSTUDENT`

## 11. JSONB CTE SQL 實作方式

1. 將匯入 DTO 以 `Newtonsoft.Json` 序列化為 JSON 陣列。
2. 以 `SqlLiteralHelper.Escape` 處理單引號後嵌入 SQL。
3. 使用單一 CTE：
   - `jsonb_array_elements` 展開輸入
   - `LEFT JOIN rank_override` 依自然鍵找既有資料
   - `UPDATE ... RETURNING`
   - `INSERT ... WHERE current_id IS NULL RETURNING`
4. 最後聚合回傳 `inserted_count`、`updated_count`
5. 相容 PostgreSQL 9.6／16／17；未使用 `MERGE`

---

## 12. 新增、更新筆數取得方式

Upsert SQL 最終 SELECT：

```sql
COUNT(CASE WHEN action = 'inserted' THEN 1 END) AS inserted_count
COUNT(CASE WHEN action = 'updated' THEN 1 END) AS updated_count
```

匯入完成訊息：

```text
匯入學年分項排名完成。
新增筆數：{n}
更新筆數：{m}
```

即使 0／0 仍視為成功。
