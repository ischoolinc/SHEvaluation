##### 1. `GetLearningHistoryReScoreData()`
**功能說明：** 從學習歷程資料表取得學生補修資料

**方法簽名：**
```csharp
public List<SubjectScoreRec108> GetLearningHistoryReScoreData(int schoolYear, int semester, List<string> studentIDList, string serialNo = "4.3")
```

**參數說明：**
- `schoolYear` (int): 學年度
- `semester` (int): 學期
- `studentIDList` (List<string>): 學生ID列表
- `serialNo` (string): 學習歷程工作表編號，預設為"4.3"

**回傳值：** `List<SubjectScoreRec108>` - 補修資料列表

**主要功能：**
1. **資料庫查詢**：從 `j_subject_info` 和 `j_subject_detail` 資料表查詢補修資料
2. **資料組織**：將查詢結果組織成結構化的 `SubjectScoreRec108` 物件
3. **欄位對應**：處理所有 4.3 相關欄位 (4.3.1 ~ 4.3.23)
4. **StudentID設定**：正確設定 `StudentID` 屬性為資料庫中的 `ref_student_id`
5. **資料驗證**：確保資料完整性和正確性
6. **日誌記錄**：詳細記錄處理過程和結果

**SQL 查詢語句：**
```sql
WITH student_score AS (
    SELECT
        ref_student_id AS student_id,
        serial_no,
        name,
        school_year,
        semester,
        subject,
        subj_level,
        jsonb_array_elements(detail) AS detail
    FROM
        student_learning_history
    WHERE              
        serial_no = '4.3'
        AND name = '補修成績'
        AND school_year = {學年度}

        AND ref_student_id IN ({學生ID列表})
),
score_pivot AS (
    SELECT
        student_id,
        serial_no,

        school_year,
        semester,
        subject,
        subj_level,
        MAX(CASE WHEN detail->>'name' = '身分證號' THEN detail->>'value' END) AS "身分證號",
        MAX(CASE WHEN detail->>'name' = '出生日期' THEN detail->>'value' END) AS "出生日期",
        MAX(CASE WHEN detail->>'name' = '應修課學年度' THEN detail->>'value' END) AS "應修課學年度",
        MAX(CASE WHEN detail->>'name' = '應修課學期' THEN detail->>'value' END) AS "應修課學期",
        MAX(CASE WHEN detail->>'name' = '課程代碼' THEN detail->>'value' END) AS "課程代碼",
        MAX(CASE WHEN detail->>'name' = '開課年級' THEN detail->>'value' END) AS "開課年級",
        MAX(CASE WHEN detail->>'name' = '修課學分' THEN detail->>'value' END) AS "修課學分",
        MAX(CASE WHEN detail->>'name' = '補修成績' THEN detail->>'value' END) AS "補修成績",
        MAX(CASE WHEN detail->>'name' = '補修及格' THEN detail->>'value' END) AS "補修及格",
        MAX(CASE WHEN detail->>'name' = '補考成績' THEN detail->>'value' END) AS "補考成績",
        MAX(CASE WHEN detail->>'name' = '補考及格' THEN detail->>'value' END) AS "補考及格",
        MAX(CASE WHEN detail->>'name' = '補修方式' THEN detail->>'value' END) AS "補修方式",
        MAX(CASE WHEN detail->>'name' = '是否採計學分' THEN detail->>'value' END) AS "是否採計學分",
        MAX(CASE WHEN detail->>'name' = '質性文字描述' THEN detail->>'value' END) AS "質性文字描述",
        MAX(CASE WHEN detail->>'name' = '備註(學生姓名)' THEN detail->>'value' END) AS "備註(學生姓名)",
        MAX(CASE WHEN detail->>'name' = '備註(資料當學期班級)' THEN detail->>'value' END) AS "備註(資料當學期班級)",
        MAX(CASE WHEN detail->>'name' = '備註(資料當學期座號)' THEN detail->>'value' END) AS "備註(資料當學期座號)",
        MAX(CASE WHEN detail->>'name' = '備註(資料當學期學號)' THEN detail->>'value' END) AS "備註(資料當學期學號)",
        MAX(CASE WHEN detail->>'name' = '備註(資料次學期班級)' THEN detail->>'value' END) AS "備註(資料次學期班級)",
        MAX(CASE WHEN detail->>'name' = '備註(資料次學期座號)' THEN detail->>'value' END) AS "備註(資料次學期座號)",

    FROM
        student_score
    GROUP BY
        student_id,
        serial_no,
        name,
        school_year,
        semester,
        subject,
        subj_level
)
SELECT * FROM score_pivot
ORDER BY
```

- 使用 `MAX(CASE WHEN ... THEN ... END)` 語法將 JSON 陣列中的資料轉換為欄位

### 7. 補考成績業務邏輯

#### 7.1 成績範圍限制
- **下限**: 補考成績必須 >= 0
- **上限**: 補考成績最高以修課及格標準為限
- **無效值**: 不符合條件時設為 "-1"

#### 7.2 及格判斷標準
- **及格標準來源**: `修課及格標準` 屬性（預設 60 分）
- **及格條件**: 補考成績 >= 及格標準
- **判斷結果**:
  - `"1"`: 及格
  - `"0"`: 不及格
  - `"-1"`: 無效成績

#### 7.3 特殊處理案例
```csharp
// 補考成績 45分，及格標準 60分 → 紀錄 45分
// 補考成績 60分，及格標準 60分 → 紀錄 60分  
// 補考成績 80分，及格標準 60分 → 紀錄 60分（以及格標準為上限）
// 補考成績 -5分 → 紀錄 "-1"（無效成績）
```

## 2024年7月23日 補充：重讀(5.3)補考及格判斷方式

### 補考及格判斷邏輯（重讀 5.3）

#### 程式邏輯說明：
- 於 `ProcessLearningHistory` 方法中，針對重讀(5.3)資料（dataValue53）與學期成績（semsScore53）進行比對。
- 以 StudentID + SubjectName + SubjectLevel 為比對鍵。
- 若找到對應學期成績，將其補考成績（ReScore）填入重讀資料，並依下列邏輯判斷補考及格（ReScoreP）：

```csharp
if (!string.IsNullOrWhiteSpace(matchingSemsScore.ReScore) &&
    !string.IsNullOrWhiteSpace(matchingSemsScore.ScoreP))
{
    if (decimal.TryParse(matchingSemsScore.ReScore, out decimal reScore) &&
        decimal.TryParse(matchingSemsScore.ScoreP, out decimal scoreP))
    {
        if (reScore >= scoreP)
            dataValueRecord.ReScoreP = "1"; // 及格
        else
            dataValueRecord.ReScoreP = "0"; // 不及格
    }
    else
    {
        dataValueRecord.ReScoreP = "-1"; // 無法比較
    }
}
else
{
    dataValueRecord.ReScoreP = "-1"; // 預設值
}
```
- 若無對應學期成績，ReScoreP 設為 "-1"。

#### 判斷說明：
- ReScoreP = "1"：補考成績 >= 及格標準，視為及格。
- ReScoreP = "0"：補考成績 < 及格標準，視為不及格。
- ReScoreP = "-1"：無法比較或無對應成績，預設值。

#### 實作一致性：
- 此邏輯與補修(4.3)補考及格判斷完全一致，確保不同來源資料的補考及格判斷標準統一。

- `studentIDList` (List<string>)：學生ID列表
**回傳**：Dictionary<string, List<SubjectScoreRec108>> - 包含學生ID和成績資料的字典

**SQL 查詢語句：**
```sql
SELECT
    sems_subj_score_ext.ref_student_id,
    sems_subj_score_ext.grade_year,
    sems_subj_score_ext.semester,
    sems_subj_score_ext.school_year,
    array_to_string(xpath('//Subject/@科目', subj_score_ele), '')::text AS 科目,
    array_to_string(xpath('//Subject/@科目級別', subj_score_ele), '')::text AS 科目級別,
    array_to_string(xpath('//Subject/@原始成績', subj_score_ele), '')::text AS 原始成績,
    array_to_string(xpath('//Subject/@補考成績', subj_score_ele), '')::text AS 補考成績,
    array_to_string(xpath('//Subject/@修課及格標準', subj_score_ele), '')::text AS 修課及格標準
FROM (
    SELECT 
        sems_subj_score.*,
        unnest(xpath('//SemesterSubjectScoreInfo/Subject', xmlparse(content score_info))) as subj_score_ele
    FROM 
        sems_subj_score 
    WHERE ref_student_id IN ({學生ID列表})
) as sems_subj_score_ext
WHERE array_to_string(xpath('//Subject/@補考成績', subj_score_ele), '')::text IS NOT NULL 
    AND array_to_string(xpath('//Subject/@補考成績', subj_score_ele), '')::text != ''
ORDER BY grade_year desc, semester desc, school_year desc
```

#### 比對邏輯實作

##### 補修成績與學期成績比對
**功能**：將學期成績的補考資料填入補修成績記錄中
**比對條件**：StudentID + Subject + SubjectLevel
**處理邏輯**：

1. **資料來源**：
   - `dataValue43`：補修成績資料（來自學習歷程）
   - `semsScore43`：學期成績資料（來自學期成績表）

2. **比對流程**：
   ```csharp
   foreach (var studentData in dataValue43)
   {
       string studentID = studentData.Key;
       List<SubjectScoreRec108> dataValueList = studentData.Value;
       
       if (semsScore43.ContainsKey(studentID))
       {
           List<SubjectScoreRec108> semsScoreList = semsScore43[studentID];
           
           foreach (var dataValueRecord in dataValueList)
           {
               // 尋找對應的學期成績記錄
               var matchingSemsScore = semsScoreList.FirstOrDefault(s => 
                   s.StudentID == dataValueRecord.StudentID &&
                   s.SubjectName == dataValueRecord.SubjectName &&
                   s.GradeYear == dataValueRecord.GradeYear);
               
               if (matchingSemsScore != null)
               {
                   // 填入補考成績
                   dataValueRecord.ReScore = matchingSemsScore.ReScore;
                   
                   // 比較補考成績與及格標準
                   if (decimal.TryParse(matchingSemsScore.ReScore, out decimal reScore) &&
                       decimal.TryParse(matchingSemsScore.ScoreP, out decimal scoreP))
                   {
                       if (reScore >= scoreP)
                           dataValueRecord.ReScoreP = "1"; // 及格
                       else
                           dataValueRecord.ReScoreP = "0"; // 不及格
                   }
                   else
                   {
                       dataValueRecord.ReScoreP = "-1"; // 無法比較
                   }
               }
               else
               {
                   dataValueRecord.ReScoreP = "-1"; // 預設值
               }
           }
       }
   }
   ```

3. **ReScoreP 值說明**：
   - `"1"`：補考成績 >= 及格標準（及格）
   - `"0"`：補考成績 < 及格標準（不及格）
   - `"-1"`：無法比較或沒有對應記錄（預設值）

4. **主要特點**：
   - 使用 LINQ 的 `FirstOrDefault` 進行精確比對
   - 支援數值比較，確保比較的準確性
   - 完整的錯誤處理，避免資料異常
   - 詳細的日誌記錄，便於追蹤處理結果
