# 高中成績調整1121.md

## 調整日期
2025-11-21

## 調整檔案
`ImportExport/ImportMakeupRetakeScore.cs`

## 調整內容摘要

### 調整目標
依 2025-11-21 與 ChatGPT 討論結果，調整匯入重補修成績功能：
- 不論匯入精靈中選擇「自動判斷取得學分」或「手動判斷取得學分」，**「成績年級」欄位都必須勾選並填入正確年級**。
- 確保補修(4.3)、重修(5.2) 名冊的 GradeYear 以及學期科目成績的成績年級邏輯維持正確。

### 調整項目

#### 1. RequiredFields 初始化調整
**位置：** `InitializeImport` 方法中，`wizard.RequiredFields.AddRange` 呼叫處

**修改內容：**
- 在 RequiredFields 初始化時，將「成績年級」加入為固定必填欄位
- 修改前：`wizard.RequiredFields.AddRange("科目", "科目級別", "學年度", "學期", "是否補修成績", "補修學年度", "補修學期", "重修學年度", "重修學期");`
- 修改後：`wizard.RequiredFields.AddRange("科目", "科目級別", "學年度", "學期", "成績年級", "是否補修成績", "補修學年度", "補修學期", "重修學年度", "重修學期");`

**效果：**
- 匯入精靈欄位對應畫面中，「成績年級」會顯示為必填欄位，不對應不能進行下一步。

#### 2. 自動判斷取得學分模式調整
**位置：** `autoCheckPass.CheckedChanged` 事件處理

**修改內容：**
- 保留原有邏輯，但新增註解說明成績年級現在本來就固定必填
- 為了保險，仍然檢查一次，若被移除則補回
- 修改後程式碼：
```csharp
autoCheckPass.CheckedChanged += delegate
{
    if (autoCheckPass.Checked)
    {
        // 成績年級本來就在 RequiredFields.AddRange 中設定為必填
        // 為了保險，仍然檢查一次，若被移除則補回
        if (!wizard.RequiredFields.Contains("成績年級"))
            wizard.RequiredFields.Add("成績年級");

        if (!wizard.RequiredFields.Contains("取得學分"))
            wizard.RequiredFields.Add("取得學分");
    }
};
```

**效果：**
- 「成績年級」不會被此段程式移除，只會在需要時再補回去
- 「取得學分」在自動判斷模式下保持必填

#### 3. 手動判斷取得學分模式調整
**位置：** `manulCheckPass.CheckedChanged` 事件處理

**修改內容：**
- 將原本移除「成績年級」的程式碼註解掉
- 保留／新增註解，說明新設計：即使在手動判斷模式，「成績年級」仍然是必填
- 修改前：會同時移除「成績年級」和「取得學分」的必填限制
- 修改後：只移除「取得學分」的必填限制，「成績年級」維持必填
- 修改後程式碼：
```csharp
manulCheckPass.CheckedChanged += delegate
{
    if (manulCheckPass.Checked)
    {
        // 「成績年級」現在設計為無論自動或手動都必填，因此不可移除
        // if (wizard.RequiredFields.Contains("成績年級"))
        //     wizard.RequiredFields.Remove("成績年級");

        // 手動判斷時，只移除「取得學分」的必填限制
        if (wizard.RequiredFields.Contains("取得學分"))
            wizard.RequiredFields.Remove("取得學分");
    }
};
```

**效果：**
- 手動判斷模式下，「成績年級」仍然是必填欄位
- 「取得學分」在手動模式下可以從 RequiredFields 移除，成為非必填

## 調整理由

1. **確保資料完整性：** 確保補修/重修名冊與學期成績年級資料一致，避免 GradeYear 空白
2. **維持邏輯正確性：** 確保學期科目成績的 `semesterGradeYear` 邏輯能正確運作
3. **統一使用者體驗：** 不論選擇自動或手動判斷取得學分，成績年級都是必填，減少使用者困惑

## 驗證項目

### 測試 1：自動判斷取得學分模式
1. 開啟匯入精靈，選取「匯入重補修成績」功能
2. 在選項頁面勾選「自動判斷取得學分」
3. 進入「欄位對應」畫面：
   - 確認「成績年級」顯示為必填
   - 不對應「成績年級」時，應無法進行下一步
4. 使用一個完整的測試 Excel（有成績年級、取得學分），確認匯入流程可成功完成

### 測試 2：手動判斷取得學分模式
1. 開啟匯入精靈，切換為「手動判斷取得學分」
2. 進入「欄位對應」畫面：
   - 確認「成績年級」仍為必填欄位
   - 「取得學分」不再是必填欄位，可不對應或不填值
3. 用測試 Excel：
   - 有填「成績年級」，不填「取得學分」
   - 驗證匯入可通過
   - ValidateRow 對「成績年級」格式不正確時仍會報錯

### 測試 3：補修/重修名冊 GradeYear
1. 準備測試資料，包含：
   - 有補修成績的資料列（是否補修成績 = 是）
   - 成績年級有填值（例如 1、2、3）
2. 匯入後檢查：
   - 4.3 補修名冊與 5.2 重修名冊中，`GradeYear` 是否正確寫入匯入年級
   - 不再出現 GradeYear 空白情形

### 測試 4：學期科目成績的成績年級變更
1. 找一位已經有學期成績的學生，原本某學年度學期的成績年級已存在（例如原本為 1）
2. 匯入一筆資料，將同一學年度學期的「成績年級」改成 2
3. 匯入後檢查：
   - 該學年度學期的學期成績年級是否改成 2
   - Log 記錄中有顯示成績年級由 1 變更為 2 的紀錄

## 備註

  - `ValidateRow` 中與成績年級相關的判斷
  - `ImportPackage` 中 `semesterGradeYear` 的使用情況
- 若發現其他匯入流程也有「成績年級」欄位且存在「自動/手動判斷取得學分」選項，可考慮比照本次作法統一行為。
