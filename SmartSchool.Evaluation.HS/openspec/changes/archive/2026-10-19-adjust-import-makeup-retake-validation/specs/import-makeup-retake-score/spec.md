# Spec Delta

## Purpose

定義匯入重補修成績時，修課及格標準、補修原始成績與學期格式必須如何驗證，以及非補修列不得覆寫既有學期科目原始成績。

## ADDED Requirements

### Requirement: 修課及格標準為必要欄位
系統 MUST 將既有欄位「修課及格標準」列為必要欄位。Excel 缺少此欄時，每一筆都 MUST 被拒絕。系統 MUST NOT 新增名為「及格標準」的欄位。

#### Scenario: Excel 缺少修課及格標準
- **WHEN** 匯入檔沒有「修課及格標準」欄
- **THEN** 每一筆驗證失敗，並指出缺少必填欄位「修課及格標準」

#### Scenario: 不新增及格標準欄位
- **WHEN** 使用者查看此功能的可匯入欄位
- **THEN** 清單包含既有的「修課及格標準」，且沒有另一個「及格標準」欄位

### Requirement: 修課及格標準每筆必填且介於 0 到 100
每一筆「修課及格標準」MUST 是可解析數字，且大於等於 0、小於等於 100；小數 MUST 允許。空白、非數字或超出範圍 MUST 拒絕該筆，並把錯誤標在此欄位。

#### Scenario: 端點與小數通過
- **WHEN** 「修課及格標準」為 0、40.5 或 100
- **THEN** 此欄位驗證通過

#### Scenario: 空白、非數字或超出範圍被拒絕
- **WHEN** 「修課及格標準」為空白、-1、101 或 ABC
- **THEN** 該筆驗證失敗，錯誤標在「修課及格標準」

### Requirement: 通過驗證的修課及格標準寫入既有科目
通過驗證的「修課及格標準」MUST 寫入對應既有學期科目的「修課及格標準」，並沿用目前的寫入方式。

#### Scenario: 合法值寫入既有科目
- **WHEN** 列通過驗證，且該學生在指定學年度、學期已有相同科目與科目級別
- **THEN** 該學期科目的修課及格標準更新為 Excel 的值

### Requirement: 原始成績欄位仍須存在
Excel MUST 包含「原始成績」欄。缺少此欄時 MUST 拒絕匯入。欄位存在不表示每一列都要驗證或寫回儲存格內容。

#### Scenario: 缺少原始成績欄
- **WHEN** Excel 沒有「原始成績」欄
- **THEN** 驗證以缺少必填欄位拒絕該批資料

### Requirement: 補修時原始成績必填且可解析
「是否補修成績」為「是」時，「原始成績」MUST 非空白且可解析為數字。空白或非數字 MUST 拒絕該筆，錯誤標在「原始成績」。系統 MUST NOT 對原始成績另加 0 到 100 的範圍限制。空白的「是否補修成績」MUST 先視為「否」，再決定原始成績是否必填。

#### Scenario: 補修是且原始成績空白
- **WHEN** 「是否補修成績」為「是」，且「原始成績」為空白
- **THEN** 該筆驗證失敗，錯誤標在「原始成績」

#### Scenario: 補修是且原始成績非數字
- **WHEN** 「是否補修成績」為「是」，且「原始成績」為 ABC
- **THEN** 該筆驗證失敗，錯誤標在「原始成績」

#### Scenario: 補修是且原始成績為數字
- **WHEN** 「是否補修成績」為「是」，且「原始成績」為可解析數字
- **THEN** 原始成績的格式驗證通過

#### Scenario: 是否補修成績空白視為否
- **WHEN** 「是否補修成績」為空白，且「原始成績」為 ABC
- **THEN** 系統把該列視為非補修，且不因原始成績內容拒絕該列

### Requirement: 非補修忽略 Excel 原始成績
「是否補修成績」為「否」時，系統 MUST NOT 驗證 Excel「原始成績」，也 MUST NOT 用它覆寫既有學期科目的原始成績。既有原始成績 MUST 保留。

#### Scenario: 補修否且原始成績為空白、數字或文字
- **WHEN** 「是否補修成績」為「否」，且 Excel「原始成績」為空白、數字或 ABC
- **THEN** 驗證不因原始成績失敗，且既有學期科目原始成績維持原值

#### Scenario: 補修是時仍更新原始成績
- **WHEN** 「是否補修成績」為「是」，且原始成績已通過驗證
- **THEN** 系統依既有補修流程更新該學期科目的原始成績

### Requirement: 重修成績格式驗證維持獨立
「重修成績」MUST 維持空白或可解析數字的既有檢查。放寬非補修列的原始成績 MUST NOT 同時放寬重修成績。

#### Scenario: 重修成績為文字
- **WHEN** 「重修成績」為 ABC
- **THEN** 該欄位驗證失敗，即使「是否補修成績」為「否」

### Requirement: 有值的補修學期與重修學期只能是 1 或 2
「補修學期」或「重修學期」只要有值，就 MUST 是整數 1 或 2。未觸發條件式必填時，空白 MUST 允許。

#### Scenario: 學期有值但不是 1 或 2
- **WHEN** 「補修學期」或「重修學期」為 0、3、1.5 或文字
- **THEN** 該欄位驗證失敗

#### Scenario: 未觸發條件式必填時空白允許
- **WHEN** 「是否補修成績」為「否」且「補修學期」空白，或「重修成績」空白且「重修學期」空白
- **THEN** 該學期欄位不因空白而失敗

#### Scenario: 整數 1 或 2 通過
- **WHEN** 「補修學期」或「重修學期」為 1 或 2
- **THEN** 該學期欄位的格式驗證通過

### Requirement: 補修與重修的條件式必填維持
「是否補修成績」為「是」時，「補修學年度」與「補修學期」MUST 有值。「重修成績」有值時，「重修學年度」與「重修學期」MUST 有值。學年度的既有數值檢查 MUST 維持，且 MUST NOT 改成只能填 1 或 2。

#### Scenario: 補修是但缺學年度或學期
- **WHEN** 「是否補修成績」為「是」，且「補修學年度」或「補修學期」空白
- **THEN** 驗證失敗並指出補修學年度、補修學期必填

#### Scenario: 重修成績有值但缺學年度或學期
- **WHEN** 「重修成績」有值，且「重修學年度」或「重修學期」空白
- **THEN** 驗證失敗並指出重修學年度、重修學期必填

### Requirement: 同一列可同時補修與重修
同一列同時符合補修與重修條件時，系統 MUST 同時產生補修名冊與重修名冊資料，MUST NOT 把兩條流程改成互斥。

#### Scenario: 同一列兩種條件都符合
- **WHEN** 同一列「是否補修成績」為「是」且原始成績合法，同時重修成績、重修學年度、重修學期皆有合法值
- **THEN** 該列同時進入補修名冊與重修名冊

### Requirement: 無關欄位不得清掉已成立的變更
處理補修時，系統 MUST NOT 清除該列先前已經成立的變更，以致應更新的學期科目被略過。

#### Scenario: 先變更其他欄位再處理補修
- **WHEN** 同一列已變更重修或其他允許更新的欄位，且「是否補修成績」為「是」
- **THEN** 那些已成立的變更仍會寫入學期科目

### Requirement: 只能更新既有科目成績
系統 MUST 拒絕在此功能新增學期科目成績。指定學年度、學期、科目與科目級別查無既有成績時，該列 MUST 失敗。

#### Scenario: 查無既有科目
- **WHEN** 該學生在指定學年度與學期沒有相同科目與科目級別的成績
- **THEN** 該列驗證失敗，且不新增學期科目成績

### Requirement: 取得學分與名冊公式維持現況
系統 MUST 維持既有自動與手動取得學分、重修擇優與及格標準截斷，以及補修 4.3、重修 5.2 名冊的寫入、學年度學期分組與欄位對應。非補修列的自動取得學分 MUST 使用系統既有原始成績。名冊及格判斷 MUST 繼續讀取回寫前既有學期科目上的修課及格標準，本變更 MUST NOT 改為改讀 Excel 的新修課及格標準。

#### Scenario: 非補修時自動取得學分使用既有原始成績
- **WHEN** 「是否補修成績」為「否」，且選擇自動判斷取得學分
- **THEN** 取得學分使用系統既有原始成績計算，不使用 Excel 原始成績

#### Scenario: 名冊仍讀回寫前的修課及格標準
- **WHEN** 同一列 Excel 的修課及格標準與既有學期科目不同，且該列產生補修或重修名冊
- **THEN** 名冊及格判斷仍使用回寫前的既有修課及格標準

### Requirement: 匯入精靈畫面不在本次修改
第一頁 MUST 顯示必要欄位，包含「修課及格標準」。第二頁 MUST 只顯示 Excel 中存在且不屬於必要欄位的選填欄位，預設勾選並允許取消。沒有選填欄位時第二頁可以空白，且 MUST 仍能按下一步。本變更 MUST NOT 修改共用匯入精靈，MUST NOT 自動跳頁，也 MUST NOT 為空白第二頁加入假的選填欄位。

#### Scenario: 第一頁包含修課及格標準
- **WHEN** 開啟匯入重補修成績
- **THEN** 第一頁必要欄位包含「修課及格標準」

#### Scenario: 沒有選填欄位時仍可下一步
- **WHEN** Excel 只含必要欄位
- **THEN** 第二頁可以沒有選填欄位，且下一步仍可按
