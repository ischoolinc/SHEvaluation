## Program.cs Main 方法流程分析

### 程式碼位置
```20:32:Program.cs
public static void Main()
{
    var btn = K12.Presentation.NLDPanels.Class.RibbonBarItems["資料統計"]["報表"]["成績相關報表"]["班級定期評量成績單(測試版)"];
    
    // 2018.09.27 [ischoolKingdom] Vicky依據 [H成績][H學務][06] 功能沒有設定權限管理 項目，將各功能按鈕註冊時Enable設定與系統權限綁定，權限Code使用GUID。
    RoleAclSource.Instance["班級"]["功能按鈕"].Add(new RibbonFeature("0837256D-3C8B-49E6-8A71-F5E0D1182A46", "班級定期評量成績單(測試版)"));
    K12.Presentation.NLDPanels.Class.SelectedSourceChanged += delegate
    {
        btn.Enable = K12.Presentation.NLDPanels.Class.SelectedSource.Count > 0 &&
        FISCA.Permission.UserAcl.Current["0837256D-3C8B-49E6-8A71-F5E0D1182A46"].Executable;
    };
    btn.Click += new EventHandler(Program_Click);
}
```

### 流程步驟解析

#### 1. 按鈕初始化
- 從 K12 系統的班級面板中獲取功能按鈕
- 按鈕路徑：資料統計 → 報表 → 成績相關報表 → 班級定期評量成績單(測試版)
- 將按鈕引用存儲在 `btn` 變數中

#### 2. 權限管理設定
- 日期：2018.09.27
- 開發者：ischoolKingdom 的 Vicky
- 依據：[H成績][H學務][06] 功能權限管理需求
- 權限 GUID：`0837256D-3C8B-49E6-8A71-F5E0D1182A46`
- 功能：將按鈕註冊到班級功能按鈕權限管理中

#### 3. 動態啟用/禁用控制
- 監聽班級選擇變更事件 (`SelectedSourceChanged`)
- 按鈕啟用條件：
  - 必須有選中的班級 (`SelectedSource.Count > 0`)
  - 使用者必須有執行權限 (`UserAcl.Current[權限GUID].Executable`)

#### 4. 點擊事件綁定
- 將按鈕點擊事件綁定到 `Program_Click` 方法
- 當使用者點擊按鈕時，將執行相應的功能邏輯

### 技術特點

1. **權限管理**：使用 GUID 進行權限識別，確保安全性
2. **動態控制**：根據班級選擇狀態和用戶權限動態啟用/禁用按鈕
3. **事件驅動**：使用委派和事件處理器實現響應式介面
4. **整合性**：與 K12 教育管理系統深度整合

### 注意事項

- 權限 GUID 必須與系統中註冊的權限一致
- 按鈕啟用邏輯依賴於班級選擇狀態
- 需要確保 `Program_Click` 方法已正確實作
