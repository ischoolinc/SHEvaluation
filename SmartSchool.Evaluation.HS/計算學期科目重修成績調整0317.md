# 計算學期科目重修成績調整0317

## 問題說明

當 `FillSemesterSubjectCalcScore` 內 `ruleType == "重修成績"` 時，雖然 `designate_final_score` 可作為重修來源分數，但後續 `maxScore` 比對未納入「修課直接指定總成績」，造成是否取得學分判斷可能不正確。

## 修改檔案

- WearyDogComputer.cs

## 修改位置

- `FillSemesterSubjectCalcScore` 方法內，`else if (ruleType == "重修成績")` 區塊：
  1. 在取得 `updateScoreElement` 之後、`passscore` 計算之前：當 `useDesignate` 為 true 時，寫入 XML 屬性「修課直接指定總成績」。
  2. 在「做取得學分判斷」的「抓最高分」區段：將 `scoreNames` 陣列加入「修課直接指定總成績」。

## 修改內容

1. 在重修成績資料流中，當 `designate_final_score` 有值時，寫入 XML 屬性「修課直接指定總成績」。
2. 在 `ruleType == "重修成績"` 的 `maxScore` 比對欄位中，加入「修課直接指定總成績」。
3. 其餘邏輯不變。

## 修改前

- 指定總成績可作為來源分數，但不參與 `maxScore` 比對。
- 「修課直接指定總成績」未寫回 XML，也未納入最高分比較。

## 修改後

- 指定總成績除了可作為來源分數，也會寫入「修課直接指定總成績」屬性，並納入 `maxScore` 比對。
- 是否取得學分判斷可反映指定總成績。

## 驗收案例

### 驗收案例 1：有指定總成績，且高於其他分數

- 原始成績 = 50，補考成績 = 55，重修成績 = 60，指定總成績 = 80，修課及格標準 = 60。
- 預期：`maxScore` 應取 80，是否取得學分判斷應使用包含指定總成績後的最大值。

### 驗收案例 2：有指定總成績，但低於其他分數

- 原始成績 = 70，重修成績 = 60，指定總成績 = 50。
- 預期：`maxScore` 應維持 70，其他邏輯不受影響。

### 驗收案例 3：沒有指定總成績

- 預期：行為與修改前一致，不應產生額外副作用。

## 驗收

- 有指定總成績且較高時，`maxScore` 應取指定總成績。
- 無指定總成績時，邏輯維持原樣。
