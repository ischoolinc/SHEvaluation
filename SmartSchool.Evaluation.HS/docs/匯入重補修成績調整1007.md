# 匯入重補修成績調整 1007

## 修改日期

2026-10-07

## 修改檔案

- `ImportExport/ImportMakeupRetakeScore.cs`

## 問題原因

上一版在 `ValidateRow` 用 `HashSet<string>` 記錄已經回報過的缺少欄位。第一筆會寫入「缺少必填欄位」，後面的資料列發現同一個欄位缺少時不再寫錯誤，卻仍然提前結束驗證。

`ImportStudentV2` 會把 `ErrorMessage` 與 `ErrorFields` 都是空的資料列當成驗證成功。後面的列因此沒有做內容驗證，畫面上也會顯示為通過。

## 修改前後規則比較

| 項目 | 修改前 | 修改後 |
|------|--------|--------|
| 17 個必填欄位 | Excel 欄位必須存在，使用者不可取消 | 相同 |
| 原始成績、重修成績 | 空白失敗，訊息「必須填寫」；有值時必須是數字 | 空白可以通過；有值但不是數字時失敗，訊息「必須填入空白或數值」 |
| 補修條件 | 是否補修成績為「是」才檢查補修學年度、補修學期 | 相同，沒有另外要求原始成績必填 |
| 重修條件 | 重修成績有值才檢查重修學年度、重修學期 | 相同，重修成績空白不要求學年度與學期 |
| 缺欄位 | 只在第一筆產生錯誤，後續資料列提前返回且沒有錯誤 | 欄位結構每輪只檢查一次；缺少欄位時每一筆都帶同一個錯誤 |

成績計算、學期科目成績更新、補修 4.3 名冊、重修 5.2 名冊沒有改動。

## Excel 欄位存在檢查方式

`requiredImportFields` 只有一份，同時交給 `wizard.RequiredFields`。17 個欄位是：

科目、科目級別、學年度、學期、成績年級、是否補修成績、補修學年度、補修學期、重修學年度、重修學期、學分數、分項類別、必選修、校部訂、原始成績、重修成績、取得學分。

自動判斷與手動判斷取得學分都不會把「成績年級」或「取得學分」移出必填。

`ImportStudentV2.CheckFile` 在選取 Excel 後，用 `RequiredFields` 對表頭做一次比對。缺少欄位時顯示「缺少必要欄位」，並停用下一步，因此不會進入 `ValidateRow` 或 `ImportPackage`。`ValidateStart` 只有學生編號，沒有欄位清單。

`ValidateRow` 保留第二層檢查，避免匯入欄位不完整時仍被當成成功：

- 每一輪驗證只在第一筆建立 `HashSet<string>`，比對一次 `requiredImportFields`。
- 缺少欄位時組成一次錯誤訊息，列出每個缺少欄位，格式為「缺少必填欄位：」加上欄位名稱。
- 同一輪後面的每一筆都寫入這則訊息並結束，不進入內容驗證。
- `ValidateStart` 會清掉這次結果，下一輪重新檢查。

`ImportStudentV2` 只有在錯誤筆數為 0 時才啟用完成匯入。每一筆都有錯誤時，這些資料不會進入 `ImportPackage`。

## 原始成績與重修成績驗證調整

```csharp
case "原始成績":
case "重修成績":
    if (value != "" && !decimal.TryParse(value, out d))
    {
        inputFormatPass = false;
        e.ErrorFields.Add(field, "必須填入空白或數值");
    }
    break;
```

兩個欄位都必須出現在 Excel。內容可以空白。有值時必須是數字。

## 補修與重修條件式驗證確認

是否補修成績為「是」時，補修學年度、補修學期不可空白，而且必須是整數。空白會先改成「否」；為「否」時不檢查補修學年度、補修學期，也不寫補修名冊。補修為「是」時，沒有另外把原始成績改成必填。

重修成績有值時，重修學年度、重修學期不可空白，而且必須是整數。重修成績空白時，格式驗證可以通過，也不要求重修學年度、重修學期。

## 缺欄位錯誤處理方式

缺少任何必填欄位時，該輪每一筆資料的 `ErrorMessage` 都是同一則缺少欄位訊息。後續資料列不會因為少寫一次訊息而變成驗證成功。

正常從匯入精靈選檔時，表頭缺少欄位會在 `CheckFile` 被擋下，不會對每一列各產生一次缺欄位錯誤。

## 效能最佳化方式

必填清單只定義一次，必填設定與缺欄位檢查共用 `requiredImportFields`。欄位是否存在只在該輪第一筆掃描，比對使用 `HashSet<string>`。後面的資料列只套用已經組好的訊息。學生資料載入與批次寫入沒有調整。
