```csharp
string qry = @"
WITH stud_gp_id AS(
    SELECT
        student.id,
        COALESCE(
            student.ref_graduation_plan_id,
            class.ref_graduation_plan_id
        ) AS graduation_plan_id
    FROM
        student
        LEFT JOIN class ON student.ref_class_id = class.id
)
SELECT
    stud_gp_id.id AS student_id,
    graduation_plan.moe_group_code AS gdc_code
FROM
    stud_gp_id
    INNER JOIN graduation_plan 
        ON stud_gp_id.graduation_plan_id = graduation_plan.id
WHERE
    stud_gp_id.id IN(" + string.Join(",", studIDList.ToArray()) + @");";
```

## 修改說明

### 主要變更
1. **資料來源變更**：從直接使用 `student.gdc_code` 或 `class.gdc_code` 改為透過 `graduation_plan.moe_group_code` 取得
2. **查詢邏輯**：
   - 使用 CTE (Common Table Expression) 先取得學生的畢業規劃 ID
   - 透過 `COALESCE(student.ref_graduation_plan_id, class.ref_graduation_plan_id)` 取得畢業規劃 ID
   - 再 JOIN `graduation_plan` 表取得 `moe_group_code` 作為 `gdc_code`
3. **保持相容性**：後續程式碼（第 224-230 行）保持不變，仍使用 `dr["gdc_code"]` 取得群組代碼

### 未變更的部分
- 後續處理 GDCCode 的程式碼邏輯（第 224-230 行）保持不變
- 學期歷程 XML 的建立與更新邏輯保持不變
- 其他計算學期科目成績的邏輯保持不變
