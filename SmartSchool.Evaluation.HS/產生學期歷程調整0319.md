# 產生學期歷程調整 0319

## 調整目的

4.2 新增時，若 5.3 已存在相同**學生系統編號 + 科目名稱 + 級別**，則不加入該筆 4.2。

## 修改檔案

* `StudentLearningHistoryProcessor.cs`

## 修改重點

1. **新增讀取 5.3 資料**
   * 在 4.2 主流程 `foreach (StudentRecord studRec in StudentRecList)` 之前，呼叫 `GetLearningHistoryRetakeDataAsDictionary53(_SchoolYear, _Semester, studentIDList)` 取得 5.3 資料。

2. **建立 5.3 比對 key 集合**
   * 將回傳的 5.3 資料整理成 `HashSet<string> exist53KeySet`。
   * key 格式：`StudentID.Trim() + "_" + SubjectName.Trim() + "_" + SubjectLevel.Trim()`，null 以空字串處理。

3. **在 4.2 加入前先檢查是否已存在 5.3**
   * 原本 `if (ssr.isScScore == false) SubjectScoreRec108List.Add(ssr);` 改為：先組出同格式的 key42，若 `exist53KeySet.Contains(key42)` 則 `continue`，否則才 `SubjectScoreRec108List.Add(ssr)`。

## 驗證結果

* 5.3 已存在時，4.2 不加入。
* 5.3 不存在時，4.2 正常加入。
* 級別不同時，4.2 仍可加入（key 含級別，視為不同）。
* 科目名稱／級別前後空白經 Trim() 後比對一致；SubjectLevel 為 null 時以空字串處理，無 null 例外。
