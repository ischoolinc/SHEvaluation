# 匯入學期科目成績調整 0921

## 修改檔案

- `ImportExport/ImportSemesterSubjectScore.cs`

## 原始行為

當勾選「自動判斷取得學分」時，三條路徑皆僅以學生及格標準判斷：

```csharp
maxScore >= _StudentPassScore[studentRec][gy]
```

「修課及格標準」雖已驗證並寫入 XML，但未參與自動取得學分判斷。

## 新及格標準優先順序

```text
修課及格標準有有效數值
    → 優先使用修課及格標準

修課及格標準沒有有效數值
    → 使用原本學生及格標準 _StudentPassScore[studentRec][gy]
```

## 修改位置

三條自動判斷取得學分路徑皆已套用相同規則：

| 路徑 | 約略行號 | 說明 |
|------|----------|------|
| 更新既有科目成績 | ~691–698 | 自 `score.Detail` 讀取「修課及格標準」 |
| 既有學期 + 新增科目 | ~884–891 | 自 `newScore` 讀取「修課及格標準」 |
| 全新學期 + 新增科目 | ~1038–1045 | 自 `newScore` 讀取「修課及格標準」 |

各路徑新增邏輯：

```csharp
decimal passScore = _StudentPassScore[studentRec][gy];
decimal coursePassScore;
if (decimal.TryParse(..., "修課及格標準", out coursePassScore))
{
    passScore = coursePassScore;
}
// maxScore >= passScore
```

- [x] 既有學期新增科目
- [x] 全新學期新增科目
