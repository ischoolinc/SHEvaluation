## 四、補修成績維持原本判斷

當：

是否補修成績 = 是

必須檢查：

- 補修學年度不可空白。
- 補修學期不可空白。
- 補修學年度必須是整數。
- 補修學期必須是整數。

就強制原始成績必填」的規則。

維持原始版本行為。

## 六、其他欄位內容規則

以下欄位保留目前已實作的驗證規則。

## 七、缺少 Excel 欄位的檢查

目前程式使用：

reportedMissingRequiredFields

以及：

foreach (string requiredField in requiredImportFields)

檢查是否缺少必填欄位。

請檢查此段是否有以下問題：

1. 第一筆資料發現缺少欄位，會產生錯誤。
2. 第二筆資料缺少相同欄位時，不再產生錯誤。
3. 第二筆資料仍會提前 return。
4. 可能造成資料列沒有錯誤訊息卻未執行驗證。

請修正此問題。

要求：

- 缺少任何必填欄位時，整批資料不得匯入。
- 必須明確列出缺少哪些欄位。
- 不可因為使用 HashSet 去除重複訊息，
  導致後續資料被視為驗證成功。
- 不要讓未經完整驗證的資料進入 ImportPackage。

優先評估 ImportWizard 是否有適合的欄位結構驗證階段。

若框架支援：
- 整份 Excel 欄位只檢查一次。
- 缺少欄位立即阻止匯入。

若框架不支援：
- 保留 ValidateRow 檢查。
- 確保每筆受到影響的資料都有有效錯誤狀態。
- 避免不必要的重複運算。

注意：
不可只使用 bool 或 HashSet 記錄已檢查，
卻讓後續資料列跳過錯誤回報。

必須確認 SmartSchool ImportWizard 的實際驗證機制。


## 八、效能最佳化

目標：
避免大量資料匯入時重複執行不必要的欄位結構檢查。

建議：
1. requiredImportFields 只定義一次。
2. RequiredFields 與缺欄位驗證共用同一份清單。
3. 優先在匯入開始時檢查 Excel 欄位結構。
4. 若可一次檢查，不要每筆重複檢查。
5. 可以使用 HashSet<string> 加速欄位比對。
6. 不要為了效能犧牲錯誤驗證的正確性。

不要調整原本學生資料載入與批次寫入方式。
