## 4. ref_exam_id 條件調整

原本：

```sql
AND ro.ref_exam_id IS NULL
```

改為：

```sql
AND ro.ref_exam_id = -1
```

學年資料條件維持：

```text
semester = -1
ref_exam_id = -1
```

## 5. extension JSONB 查詢方式

在同一筆 `GetSchoolYearEntryRanksByStudentID` 查詢內使用：

```sql
CROSS JOIN LATERAL
    jsonb_array_elements(
        COALESCE(ro.extension, '[]'::jsonb)
    ) AS ext
```

並加上：

```sql
AND ext->>'extension_name' = '排名資料'
```

沒有 extension、或 extension 不是「排名資料」的資料不會進入結果。

未另外建立第二次資料庫查詢。

## 6. lvData 六欄與資料來源

| lvData 欄位 | 來源 |
|---|---|
| 學年度 | `ro.school_year` |
| 成績類型 | `ext->>'成績類型'` |
| 成績項目 | `ext->>'成績項目'` |
| 排名範圍 | `ro.rank_type` |
| 建立時間 | `ext->>'create_time'`（解析後顯示） |
| 建立方式 | `ext->>'建立方式'` |

成績類型／成績項目刻意不使用 `ro.item_type`、`ro.item_name`。

預期顯示範例：

```text
113 | 學年 | 分項 | 班排名 | 2026/8/11 00:37 | 匯入
```

## 7. create_time 解析與顯示

`MapRankRecord` 呼叫 `FormatCreateTime`：

1. 空值 → 空白
2. `DateTimeOffset.TryParse` 成功 → `yyyy/M/d HH:mm`
3. 解析失敗 → 保留原始字串，不拋 Exception

## 8. SchoolYearEntryRankRecord 新增欄位

保留既有：

```text
ID、StudentID、SchoolYear、GradeYear、RankName、Rank
以及匯出用學生欄位
```

新增：

```csharp
public string ScoreType { get; set; }
public string ScoreItem { get; set; }
public string RankType { get; set; }
public string CreateTime { get; set; }
public string CreateMethod { get; set; }
```

`MapRankRecord` 以 `row.Table.Columns.Contains(...)` 安全對應，避免影響匯出路徑 `GetSchoolYearEntryRanksByStudentIDs`（該查詢未選取新欄位）。
