# 畢業預警調整 0508

## 修改項目

調整 `GraduateEvaluator.cs` 中「尚未補修」判斷條件。

## 修改前

尚未補修判斷條件：

- 是否補修成績 = 是
- 補修學年度 = 空值
- 補修學期 = 空值

## 修改後

尚未補修判斷條件：

- 是否補修成績 = 是
- 原始成績 = 空值

## 調整原因

補修學年度、補修學期不再作為尚未補修判斷依據。

改以「是否補修成績=是」且「原始成績為空值」判斷是否寫入尚未補修。

## 影響範圍

- 畢業預警報表中科目狀態為「尚未補修」的資料。
- `check.MakeupCount` 的累加條件。

## 驗證結果

- 是否補修成績=是 且 原始成績空值：會寫入尚未補修。
- 是否補修成績=是 且 原始成績有值：不會寫入尚未補修。
- 是否補修成績不是是：不會寫入尚未補修。

## 實作細節

於 `if (subjectElement != null)` 內、`switch (check.Type)` 之前新增共用變數：

```csharp
bool isUnMakeupScore =
    subjectScore.Detail.GetAttribute("是否補修成績") == "是"
    && subjectScore.Detail.GetAttribute("原始成績").Trim() == "";
```

兩處原本的「尚未補修」判斷皆改為使用 `isUnMakeupScore`：

1. `case "修課學分數統計":` 區塊內判斷已修 / 尚未補修。
2. `case "取得學分數統計":` 區塊內、`subjectScore.Pass` 為 false 時判斷可重修 / 尚未補修。

## 變更檔案

- `WearyDogComputerHelper/GraduateEvaluator.cs`

## 可補修判斷修改

### 問題

當資料為：

- 是否補修成績 = 是
- 原始成績 = 空白
- 是否取得學分 = 是

原本仍會被判斷為尚未補修 / 可補修。

### 原因

`isUnMakeupScore` 只判斷：

- 是否補修成績 = 是
- 原始成績 = 空白

沒有排除已取得學分的資料。

### 修改方式

在 `isUnMakeupScore` 加入：

```csharp
&& !subjectScore.Pass
```

### 修改後結果

只有未取得學分，且符合補修成績與原始成績空白條件的資料，才會被列入尚未補修 / 可補修。
