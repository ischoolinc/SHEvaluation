# 學期歷程成績抵免調整0324

## 修改目的

- 僅保留 `4.2 一般學期成績流程` 的抵免判斷。
- 註解掉 `4.4 / 6.2 / 6.4` 的抵免判斷，避免因 `抵免 = 是` 直接改為 `useCredit = "2"`。

## 修改檔案

- `StudentLearningHistoryProcessor.cs`

## 修改方式

- `4.2` 保留原邏輯，不調整：
  - `ssr.useCredit = "1";`
  - `if (Utility.GetAttribute(elmScore, "抵免") == "是") ssr.useCredit = "2";`
- `4.4 / 6.2 / 6.4` 三處改為註解（僅註解、不刪除）：
  - `// if (Utility.GetAttribute(elmScore, "抵免") == "是")`
  - `//     ssr.useCredit = "2";`
- 保留 `9D` 覆蓋邏輯，不影響 `ssr.useCredit = "3"` 判斷。

## 驗證結果

- `4.2` 仍可在 `抵免 = 是` 時產生 `useCredit = "2"`。
- `4.4 / 6.2 / 6.4` 不再因 `抵免 = 是` 變成 `"2"`（維持 `"1"`，除非被其他規則覆蓋）。
- `9D` 課程仍可覆蓋為 `useCredit = "3"`。
