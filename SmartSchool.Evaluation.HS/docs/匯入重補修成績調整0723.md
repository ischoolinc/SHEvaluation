#### 新增方法：

##### 1. `GetLearningHistoryReScoreData()`
**功能說明：** 從學習歷程資料表取得學生補修資料

**方法簽名：**
```csharp
public List<SubjectScoreRec108> GetLearningHistoryReScoreData(int schoolYear, int semester, List<string> studentIDList, string serialNo = "4.3")
```

**參數說明：**
- `schoolYear` (int): 學年度
- `semester` (int): 學期
- `studentIDList` (List<string>): 學生ID列表
- `serialNo` (string): 學習歷程工作表編號，預設為"4.3"

**回傳值：** `List<SubjectScoreRec108>` - 補修資料列表

**主要功能：**
1. **資料庫查詢**：從 `j_subject_info` 和 `j_subject_detail` 資料表查詢補修資料
2. **資料組織**：將查詢結果組織成結構化的 `SubjectScoreRec108` 物件
3. **欄位對應**：處理所有 4.3 相關欄位 (4.3.1 ~ 4.3.23)
4. **StudentID設定**：正確設定 `StudentID` 屬性為資料庫中的 `ref_student_id`
5. **資料驗證**：確保資料完整性和正確性
6. **日誌記錄**：詳細記錄處理過程和結果

**SQL 查詢語句：**
```sql
SELECT 
    j_subject_info.ref_student_id,
    j_subject_info.school_year,
    j_subject_info.semester,
    j_subject_info.subject,
    j_subject_info.subject_level,
    j_subject_detail.serial_no,
    j_subject_detail.name,
    j_subject_detail.value
FROM j_subject_info 
LEFT JOIN j_subject_detail ON j_subject_info.id = j_subject_detail.ref_j_subject_info_id
WHERE j_subject_info.serial_no = '4.3'
    AND j_subject_info.school_year = {學年度}
    AND j_subject_info.semester = {學期}
    AND j_subject_info.ref_student_id IN ({學生ID列表})
ORDER BY 
    j_subject_info.ref_student_id, j_subject_detail.serial_no;
```

##### 2. `GetStudentsWithReScoreData()`
**功能說明：** 取得有學習歷程補修資料的學生ID列表

**方法簽名：**
```csharp
public List<string> GetStudentsWithReScoreData(int schoolYear, int semester, string serialNo = "4.3")
```

**參數說明：**
- `schoolYear` (int): 學年度
- `semester` (int): 學期
- `serialNo` (string): 學習歷程工作表編號，預設為"4.3"

**回傳值：** `List<string>` - 有補修資料的學生ID列表

**SQL 查詢語句：**
```sql
SELECT DISTINCT 
    j_subject_info.ref_student_id
FROM j_subject_info 
WHERE j_subject_info.serial_no = '4.3'
    AND j_subject_info.school_year = {學年度}
    AND j_subject_info.semester = {學期}
```

##### 3. `GetLearningHistoryReScoreDataAsDictionary()`
**功能說明：** 取得學習歷程補修資料並建立以StudentID為key的Dictionary

**方法簽名：**
```csharp
public Dictionary<string, List<SubjectScoreRec108>> GetLearningHistoryReScoreDataAsDictionary(int schoolYear, int semester, List<string> studentIDList, string serialNo = "4.3")
```

**參數說明：**
- `schoolYear` (int): 學年度
- `semester` (int): 學期
- `studentIDList` (List<string>): 學生ID列表
- `serialNo` (string): 學習歷程工作表編號，預設為"4.3"

**回傳值：** `Dictionary<string, List<SubjectScoreRec108>>` - 包含學生ID和補修資料的字典

**處理流程：**
1. 使用 `GetLearningHistoryReScoreData` 取得補修資料
2. 將資料按學生ID分組（使用 `StudentID` 屬性）
3. 回傳以StudentID為key的字典

#### 使用範例：

```csharp
var processor = new StudentLearningHistoryProcessor();

// 方法1：直接取得特定學生的補修資料
List<string> studentIDs = new List<string> { "學生ID1", "學生ID2", "學生ID3" };
List<SubjectScoreRec108> reScoreData = processor.GetLearningHistoryReScoreData(110, 1, studentIDs);

// 方法2：先取得有資料的學生ID，再取得補修資料
List<string> studentsWithData = processor.GetStudentsWithReScoreData(110, 1);
List<SubjectScoreRec108> reScoreData2 = processor.GetLearningHistoryReScoreData(110, 1, studentsWithData);

// 方法3：取得補修資料並建立Dictionary
List<string> studentIDs = new List<string> { "學生ID1", "學生ID2", "學生ID3" };
Dictionary<string, List<SubjectScoreRec108>> result = processor.GetLearningHistoryReScoreDataAsDictionary(110, 1, studentIDs);
```
