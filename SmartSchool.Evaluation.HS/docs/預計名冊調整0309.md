# 預計名冊調整0309

## 1. 修改檔案名稱
- `Process\Wizards\LearningHistory\LearningHistoryDataAccess.cs`

## 2. 修改 method 名稱
- `GetSCAttendCourseRows(int schoolYear, int semester, List<string> studentIds)`

## 3. 原本 SQL 條件
```sql
AND COALESCE(course.not_included_in_calc, '0') <> '1'
AND COALESCE(course.not_included_in_credit, '0') <> '1'
```

## 4. 調整後 SQL 條件
```sql
AND char_length(COALESCE(sc_attend.subject_code, '')) = 23
AND COALESCE(course.not_included_in_credit, '0') = '0'
AND (
       COALESCE(course.not_included_in_calc, '0') = '0'
    OR (
           COALESCE(course.not_included_in_calc, '0') = '1'
           AND upper(substring(sc_attend.subject_code from 17 for 2)) = '9D'
       )
)
```

## 5. 調整原因
- 預檢名冊課程取得需依新規則：`subject_code` 須為 23 碼；不計學分必須為「否」；不需評分為「否」時取得，不需評分為「是」時僅當第 17~18 碼為 `9D`/`9d` 才取得。
- 原條件僅排除「不需評分」與「不計學分」為「是」的課程，未限制 `subject_code` 長度，也未允許「不需評分=是」但符合 9D 的課程。

## 6. 驗證結果摘要
| 不需評分 | 不計學分 | subject_code 長度 | 第17~18碼 | 是否取得 |
|---------|---------|------------------|-----------|---------|
| 否 | 否 | 23 | 任意 | 取得 |
| 是 | 否 | 23 | 9D / 9d | 取得 |
| 是 | 否 | 23 | 非 9D / 9d | 不取得 |
| 否 | 是 | 23 | 任意 | 不取得 |
| 是 | 是 | 23 | 任意 | 不取得 |
| 否 | 否 | 非 23 | 任意 | 不取得 |
| 是 | 否 | 非 23 | 9D / 9d | 不取得 |

## 7. 是否同步修改兩段 SQL
- 是。已同步修改「預設學年期」與「非預設學年期」兩段 SQL 的課程過濾條件，兩段條件一致。
