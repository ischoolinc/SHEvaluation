## 規則說明

### 資料庫定義
- `course.not_included_in_calc = '1'` 表示：**不需評分 = 是**
- `course.not_included_in_credit = '1'` 表示：**不計學分 = 是**

### 本次課程取得條件
只有符合以下規則才取得：

1. `subject_code` 長度必須為 **23 碼**
2. 當 **不需評分 = 否** 且 **不計學分 = 否** 時，取得
3. 當 **不需評分 = 是** 且 **不計學分 = 否** 時，只有 `subject_code` 第 17 碼起取 2 碼為 **`9D`** 或 **`9d`** 才取得
4. 以下情況不取得：
   - 不需評分 = 否，且 不計學分 = 是
   - 不需評分 = 是，且 不計學分 = 是
   - `subject_code` 長度不是 23 碼
   - 不需評分 = 是、 不計學分 = 否，但 `subject_code` 第 17~18 碼不是 `9D` / `9d`

## 最終建議 SQL 條件
請將原本用來過濾 `not_included_in_calc` / `not_included_in_credit` 的條件，改成以下條件：

```sql
AND char_length(COALESCE(sc_attend.subject_code, '')) = 23
AND COALESCE(course.not_included_in_credit, '0') = '0'
AND (
       COALESCE(course.not_included_in_calc, '0') = '0'
    OR (
           COALESCE(course.not_included_in_calc, '0') = '1'
           AND upper(substring(sc_attend.subject_code from 17 for 2)) = '9D'
       )
)
```

---

## 條件解讀
這個條件代表：

1. 所有要取得的課程，`subject_code` 都必須是 23 碼
2. `不計學分` 必須為 `否`
3. 之後再分成兩種可取得情況：
   - `不需評分 = 否` → 可取得
   - `不需評分 = 是` → 必須再檢查 `subject_code` 第 17~18 碼為 `9D` / `9d`
4. `upper(...) = '9D'` 可同時支援大小寫
