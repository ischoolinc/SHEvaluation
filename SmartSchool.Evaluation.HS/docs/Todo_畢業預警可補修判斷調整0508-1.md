
# Cursor Todo.md - 可補修判斷修改

## 目標

修改 `GraduateEvaluator.cs` 的可補修 / 尚未補修判斷邏輯。

目前問題：

當資料符合：

- 是否補修成績 = "是"
- 原始成績 = 空白
- 是否取得學分 = "是"

目前程式仍會被判斷為：

- 狀態 = 尚未補修
- 被列入 MakeupCount
- 報表顯示為可補修 / 需要補修

本次調整目標：

只有在：

- 是否補修成績 = "是"
- 原始成績 = 空白
- 是否取得學分 = "否" 或未取得學分

才可判斷為尚未補修 / 可補修。

已取得學分的資料，不可再列入可補修。

---

## 修改檔案

- `GraduateEvaluator.cs`

---

## 修改重點

### 1. 找到 `isUnMakeupScore` 判斷

搜尋：

```csharp
bool isUnMakeupScore =
    subjectScore.Detail.GetAttribute("是否補修成績") == "是"
    && subjectScore.Detail.GetAttribute("原始成績").Trim() == "";
````

目前邏輯只判斷：

```text
是否補修成績 = 是
原始成績 = 空
```

缺少「是否已取得學分」判斷。

---

### 2. 修改 `isUnMakeupScore` 判斷條件

將原本：

```csharp
bool isUnMakeupScore =
    subjectScore.Detail.GetAttribute("是否補修成績") == "是"
    && subjectScore.Detail.GetAttribute("原始成績").Trim() == "";
```

改成：

```csharp
bool isUnMakeupScore =
    subjectScore.Detail.GetAttribute("是否補修成績") == "是"
    && subjectScore.Detail.GetAttribute("原始成績").Trim() == ""
    && !subjectScore.Pass;
```

---

## 修改後邏輯說明

修改後，只有符合以下條件才算尚未補修 / 可補修：

```text
是否補修成績 = 是
原始成績 = 空白
subjectScore.Pass = false
```

也就是：

```text
補修成績標記為是
但沒有原始成績
而且沒有取得學分
```

才列入可補修。

## 可補修判斷修改

### 問題

當資料為：

- 是否補修成績 = 是
- 原始成績 = 空白
- 是否取得學分 = 是

原本仍會被判斷為尚未補修 / 可補修。

### 原因

`isUnMakeupScore` 只判斷：

- 是否補修成績 = 是
- 原始成績 = 空白

沒有排除已取得學分的資料。

### 修改方式

在 `isUnMakeupScore` 加入：

```csharp
&& !subjectScore.Pass
````

### 修改後結果

只有未取得學分，且符合補修成績與原始成績空白條件的資料，才會被列入尚未補修 / 可補修。
