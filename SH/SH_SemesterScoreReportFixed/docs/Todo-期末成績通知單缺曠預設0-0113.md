# Todo - 期末成績通知單：缺曠預設 0（不影響既有判斷）- 0113

## 目標
1. 在 `Program.cs` 產生期末成績通知單的資料填入流程中，**缺曠相關欄位（缺曠類型欄位）預設為 0**。
2. 當實際缺曠統計有值時，才以實際值覆寫。
3. **不得影響**既有功能判斷與資料流（例如：欄位有無、合併欄位名稱、其他數值/文字欄位、排名/五標/區間等）。

---

## 範圍與原則

### 範圍
- 檔案：`Program.cs`
- 影響區塊：建立 `DataTable` 欄位（Columns）＋每位學生建立 `DataRow` 時填入缺曠欄位（Rows）

### 原則（最佳實作）
- **不要使用** `DataColumn.DefaultValue` 來期待自動套用（已建立 DataRow 不會回填，容易誤判有效）。
- **不要使用**「合併前檢查 DBNull 再補 0」的救火寫法（容易漏欄位、難維護）。
- 採用：**建立 DataRow 後立即初始化缺曠欄位為 0**，後續缺曠計算有值再覆寫。

---

## 既有行為（你要保留）
- 缺曠資料若查不到 key 或某缺曠項目不存在：目前常見會是 `DBNull`，Aspose 合併呈現空白。
- 本次改動後：缺曠欄位應顯示 `0`，但**不得改變**缺曠資料取得方式、key 命名規則、與其他欄位的填入順序/邏輯。

## 實作步驟（建議順序）

### Todo 1：建立缺曠欄位清單（一次性、可重用）
1. 在 `Program_Click` 建立缺曠 mapping key 的地方（你目前已組出如 `本學期一般_曠課` 等 key），整理出「缺曠欄位名稱清單」：
   - `List<string> absenceColumnNames = new List<string>();`
2. 在新增缺曠欄位到 `DataTable` 時，**同時加入清單**：
   - `table.Columns.Add(colName, typeof(int));`
   - `absenceColumnNames.Add(colName);`

**驗收**
- `absenceColumnNames` 只包含缺曠欄位，不包含其他欄位（例如：排名、五標、服務學習、地址等）。

---

### Todo 2：新增初始化方法 `InitAbsenceDefault`
建立一個小工具方法（同檔內 `private static` 亦可）：

```csharp
private static void InitAbsenceDefault(DataRow row, List<string> absenceColumnNames)
{
    foreach (var colName in absenceColumnNames)
    {
        // 防呆：欄位存在才設值，避免未來欄位調整造成例外
        if (row.Table.Columns.Contains(colName))
            row[colName] = 0;
    }
}
```

**重點**
- 僅設定缺曠欄位；不要碰其他欄位。
- 保留 `Columns.Contains` 防呆。

---

### Todo 3：在每位學生建立 DataRow 時，最早期就初始化缺曠為 0
在你目前填每位學生資料的 loop 中（通常會有 `DataRow row = table.NewRow();`）：

```csharp
DataRow row = table.NewRow();

// ✅ 最早期：先把缺曠欄位全設為 0
InitAbsenceDefault(row, absenceColumnNames);

// 後續才填學生基本資料、成績、排名等
row["姓名"] = student.Name;
...
```

**驗收**
- 就算後面缺曠統計完全沒填入/查不到 key，缺曠欄位仍會保持 0。

---

### Todo 4：缺曠有值才覆寫（維持原邏輯，只加 TryGetValue）
找到你目前填缺曠欄位的地方（可能是 `GetAttendanceCount...` 回來的字典），改成「有值才覆寫」：

```csharp
if (attendanceCountDict.TryGetValue(studentID, out var keyDict))
{
    if (keyDict.TryGetValue(absenceKey, out int count))
        row[colName] = count; // 覆寫
}
```

**注意**
- 不要新增任何「把 0 改回空白」的行為。
- 既有 key 命名、學年度/學期/期間（本學期/上學期、本學年/上學年）邏輯不要變。
