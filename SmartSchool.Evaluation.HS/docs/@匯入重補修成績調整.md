# 匯入重補修成績調整紀錄

## 2025-07-18

- 修正重修成績寫入學期歷程時的及格判斷：
  - ScoreP 現在根據「重修成績」與「修課及格標準」比較，只有當重修成績**大於及格標準**時才算及格（ScoreP=1），否則為不及格（ScoreP=0）。
  - 若重修成績無法解析，預設為不及格（ScoreP=0）。
- 修正 ReAScoreP 判斷邏輯：
  - 由「大於等於」改為「大於」及格標準，與 ScoreP 判斷一致。
- 修正自動判斷取得學分邏輯：
  - 將最高分與及格標準比較由「大於等於」改為「大於」，確保只有真正超過及格標準的成績才算及格。

## 2025-07-22

- 移除所有 `GetRowDataCellValue(row, "修課及格標準")` 的使用，改為：
  - 優先使用現有成績資料 `score.Detail.GetAttribute("修課及格標準")`
  - 若無現有成績資料，則預設為 60 分
- 影響區塊：
  - 補修、重修、補考成績及格判斷
  - 相關判斷與欄位皆已修正
- 完成移除所有使用，確保修課及格標準的取得更加準確
- 修正 `passingStandard` 變數宣告問題，確保編譯無誤
- 修正及格判斷邏輯：將 `> passScore`、`> passingStandard` 改為 `>=`，確保等於及格標準也算及格
- 「自動判斷取得學分」預設為選取，「手動判斷取得學分」預設為未選取
- 自動判斷取得學分時，優先使用系統內重修成績作為最高分初始值，再與其他成績比較
- 取得學分判斷改為使用系統內學期科目成績的修課及格標準，而非成績計算規則的及格標準

## 2025-07-23

- 修正補修成績 (isMakeupScore == "是") 的 ScoreP 資料來源：
  - 原本使用 `GetRowDataCellValue(row, "重修成績")` 作為成績來源
  - 修改為使用 `GetRowDataCellValue(row, "原始成績")` 作為成績來源
  - 及格判斷邏輯保持不變：原始成績 >= 修課及格標準 → 及格（"1"），否則不及格（"0"）
- 修改位置：
  - `ImportExport/ImportMakeupRetakeScore.cs` 第 572-583 行（補修成績處理區塊）
- 修改說明：
  - 補修成績的 ScoreP 現在使用原始成績進行及格判斷，而非重修成績
  - 確保補修成績的及格判斷更符合業務邏輯
  - 重修成績的 ScoreP 判斷邏輯保持不變，仍使用重修成績
