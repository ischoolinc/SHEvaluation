3. 比對 key 先依需求使用：

   * `學生系統編號 + 科目名稱 + 級別`

## 二、新增讀取 5.3 資料供 4.2 排除使用

在 4.2 主流程建立前，先呼叫既有方法讀取 5.3：

```csharp
GetLearningHistoryRetakeDataAsDictionary53(_SchoolYear, _Semester, studentIDList)
```

### 做法

在建立 `SubjectScoreRec108List` 之前，新增一段：

1. 呼叫 `GetLearningHistoryRetakeDataAsDictionary53(_SchoolYear, _Semester, studentIDList)`
2. 將回傳的 5.3 資料整理成 `HashSet<string>`
3. key 格式統一為：

```csharp
StudentID + "_" + SubjectName.Trim() + "_" + SubjectLevel.Trim()
```

### 建議程式碼

請放在 4.2 主流程開始前、`foreach (StudentRecord studRec in StudentRecList)` 之前，或其他同層適合位置：

```csharp
// 讀取 5.3 資料，供 4.2 排除使用
Dictionary<string, List<SubjectScoreRec108>> dataValue53For42 =
    GetLearningHistoryRetakeDataAsDictionary53(_SchoolYear, _Semester, studentIDList);

HashSet<string> exist53KeySet = new HashSet<string>();

foreach (var kv in dataValue53For42)
{
    if (kv.Value == null)
        continue;

    foreach (var rec in kv.Value)
    {
        string key53 =
            (rec.StudentID ?? "").Trim() + "_" +
            (rec.SubjectName ?? "").Trim() + "_" +
            (rec.SubjectLevel ?? "").Trim();

        if (!exist53KeySet.Contains(key53))
            exist53KeySet.Add(key53);
    }
}
```

## 三、在 4.2 加入前，先檢查 5.3 是否已存在

找到原本這段：

```csharp
if (ssr.isScScore == false)
    SubjectScoreRec108List.Add(ssr);
```

改成先判斷 5.3 是否已有相同學生系統編號 + 科目名稱 + 級別，再決定是否加入。

### 建議修改後程式碼

```csharp
if (ssr.isScScore == false)
{
    string key42 =
        (ssr.StudentID ?? "").Trim() + "_" +
        (ssr.SubjectName ?? "").Trim() + "_" +
        (ssr.SubjectLevel ?? "").Trim();

    // 若 5.3 已存在相同學生系統編號 + 科目名稱 + 級別，則不加入 4.2
    if (exist53KeySet.Contains(key42))
        continue;

    SubjectScoreRec108List.Add(ssr);
}
```

## 五、驗證重點

請至少驗證以下情境：

### 情境 1：5.3 已存在，4.2 不可加入

測試資料：

* 同一學生系統編號
* 同一科目名稱
* 同一級別
* 5.3 已存在

預期：

* 該筆不加入 `SubjectScoreRec108List`
* 最後不會寫入 4.2

### 情境 2：5.3 不存在，4.2 可正常加入

測試資料：

* 同一學生系統編號
* 科目名稱、級別在 5.3 查無資料

預期：

* 若符合原本 4.2 條件，仍正常加入 4.2

### 情境 3：同學生、同科目名稱，但級別不同

預期：

* 視為不同資料
* 4.2 可加入

### 情境 4：同學生、同級別，但科目名稱前後有空白

預期：

* 因有 `Trim()`，應視為相同
* 5.3 已存在時，4.2 不加入

### 情境 5：`SubjectLevel` 為 null 或空字串

預期：

* 不可發生 null 例外
* 比對結果符合空字串處理邏輯
