## 問題說明

目前 `FillSemesterSubjectCalcScore` 內，很多分支只有在 `studentFinalScoreDict` 有資料時，才會寫入：

* `修課及格標準`
* `修課補考標準`

但在 **更新既有學期科目成績** 或某些 **新增成績** 分支中，若沒有進入該段，會發生：

1. `修課及格標準` 保留舊值或空值
2. `修課補考標準` 保留舊值或空值
3. 後續 `是否取得學分`、`ScoreP`、`RepeatScoreP`、`ReScoreP`、`ReAScoreP` 等判斷可能使用到舊資料
4. 更新模式下，使用者修改修課的及格 / 補考標準後，重新計算學期科目成績，不會同步更新到 Subject XML

---

## 本次修改原則

1. **不要大改整體商業流程**
2. **不要改壞一般修課 / 再次修習 / 重修成績 / 補修成績 的既有判斷**
3. 改成：

   * `修課及格標準` 一律有統一寫入流程
   * `修課補考標準` 一律有統一寫入流程
4. 若 `sc_attend.passing_standard` / `sc_attend.makeup_standard` 有值，優先用該值
5. 若 `passing_standard` 沒值，fallback 到 `applyLimit`
6. 若 `applyLimit` 也沒有，`修課及格標準` fallback `60`
7. 若 `makeup_standard` 沒值，允許空白，但不要沿用舊值不更新
8. **不要只在 `studentFinalScoreDict` 存在時才更新**
9. 修改後，新增與更新模式都要一致

## 三、抽共用方法

在 `WearyDogComputer.cs` 內新增 helper method，讓所有分支統一使用。

---

### 方法 1：取得有效及格標準

建議新增：

```csharp
private decimal GetEffectivePassingStandard(
    string studentId,
    string key,
    int gradeYear,
    Dictionary<string, Dictionary<string, decimal>> studentPassScoreDict,
    Dictionary<int, decimal> applyLimit)
```

### 規則

1. 預設 `60`
2. 若 `studentPassScoreDict[studentId][key]` 有值且不為 `-1`，優先使用
3. 否則若 `applyLimit` 有 `gradeYear`，使用 `applyLimit[gradeYear]`
4. 否則使用 `60`

### 參考實作

```csharp
private decimal GetEffectivePassingStandard(
    string studentId,
    string key,
    int gradeYear,
    Dictionary<string, Dictionary<string, decimal>> studentPassScoreDict,
    Dictionary<int, decimal> applyLimit)
{
    decimal passscore = 60;

    if (studentPassScoreDict != null &&
        studentPassScoreDict.ContainsKey(studentId) &&
        studentPassScoreDict[studentId].ContainsKey(key))
    {
        decimal value = studentPassScoreDict[studentId][key];
        if (value != -1)
            return value;
    }

    if (applyLimit != null && applyLimit.ContainsKey(gradeYear))
        return applyLimit[gradeYear];

    return passscore;
}
```

* 沒值 → 清空
* 不可放著不動
