# 重補修成績匯入表調整 0615

## 修改項目

調整重補修成績匯入表 XLS 報表中 `是否補修成績` 欄位的顯示邏輯，確保匯出值一律為 `是` 或 `否`。

## 修改前顯示行為

`AddSubject()` 方法中，`是否補修成績` 欄位直接輸出 XML 屬性值：

```csharp
aInfo.Add("是否補修成績", info.Detail.HasAttribute("是否補修成績") ? info.Detail.GetAttribute("是否補修成績") : "");
```

| XML 資料 | 匯出 XLS 值 |
| -------- | ----------- |
| `是否補修成績="是"` | `是` |
| `是否補修成績="否"` | `否` |
| 屬性不存在 | `""`（空字串） |
| 屬性為空值 | `""`（空字串） |
| 其他非預期值 | 原值直接輸出 |

## 修改後顯示規則

僅當屬性存在且值為 `是` 時輸出 `是`，其餘情況一律輸出 `否`：

| XML 資料 | 匯出 XLS 值 |
| -------- | ----------- |
| `是否補修成績="是"` | `是` |
| `是否補修成績="否"` | `否` |
| 屬性不存在 | `否` |
| 屬性為空值 | `否` |
| 其他非預期值 | `否` |

## 修改檔案與方法

- 檔案：`Reports/Retake/RetakeScoreImport.cs`
- 方法：`AddSubject()`

## 實作程式碼

```csharp
aInfo.Add("是否補修成績",
    info.Detail.HasAttribute("是否補修成績") &&
    info.Detail.GetAttribute("是否補修成績") == "是"
        ? "是"
        : "否");
```
