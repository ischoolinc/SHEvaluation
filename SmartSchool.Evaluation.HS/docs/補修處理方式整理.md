## 一、補修成績概述

### 1.1 什麼是補修成績？

補修成績是指學生因某些原因（如缺修、未修）而需要補修課程所取得的成績。在系統中，補修成績透過以下方式標識：

- **是否補修成績** 欄位設為「是」
- **補修學年度** 記錄補修課程的學年度
- **補修學期** 記錄補修課程的學期

### 1.2 補修成績與重修成績的區別

| 項目 | 補修成績 | 重修成績 |
|------|---------|---------|
| 使用時機 | 學生未修過該課程 | 學生修過但不及格需重修 |
| 標識欄位 | 是否補修成績 = 是 | 重修成績欄位有值 |
| 學年度/學期欄位 | 補修學年度、補修學期 | 重修學年度、重修學期 |
| 學習歷程工作頁 | 4.3 補修成績 | 5.2 重修成績 |

## 二、補修成績的資料欄位

### 2.1 核心欄位

| 欄位名稱 | 資料型別 | 說明 | 必填 |
|---------|---------|------|------|
| 是否補修成績 | 是/否 | 標識此科目成績是否為補修成績 | 是 |
| 補修學年度 | 整數 | 補修課程所屬學年度 | 是（當是否補修成績=是時） |
| 補修學期 | 整數 (1或2) | 補修課程所屬學期 | 是（當是否補修成績=是時） |
| 原始成績 | 數值 | 補修課程的原始成績 | - |
| 補考成績 | 數值 | 補修課程的補考成績（如有） | - |

### 2.2 相關欄位

- **科目**：補修的科目名稱
- **科目級別**：補修科目的級別
- **學分數**：補修科目的學分數
- **修課及格標準**：補修科目的及格標準
- **是否取得學分**：根據成績判斷是否取得學分

## 三、補修成績的匯入功能

### 3.1 匯入功能位置

**功能路徑**：成績處理 → 重補修成績 → 匯入重補修成績  
**程式檔案**：`ImportExport/ImportMakeupRetakeScore.cs`  
**權限代碼**：00c64573-9060-4c94-ba02-cc6508c84ca8

### 3.2 匯入模式

系統提供兩種匯入模式：

#### 3.2.1 自動判斷取得學分（預設）

- 系統自動根據成績與及格標準判斷是否取得學分
- 需要提供「成績年級」欄位
- 取得學分欄位必須填入「自動」
- 系統會讀取成績計算規則中的及格標準進行判斷

#### 3.2.2 手動判斷取得學分

- 由使用者手動指定是否取得學分
- 取得學分欄位必須填入「是」或「否」
- 不需要提供「成績年級」欄位

### 3.3 匯入必填欄位

| 欄位 | 自動模式 | 手動模式 | 說明 |
|------|---------|---------|------|
| 科目 | ✓ | ✓ | 科目名稱 |
| 科目級別 | ✓ | ✓ | 科目級別 |
| 學年度 | ✓ | ✓ | 成績所屬學年度 |
| 學期 | ✓ | ✓ | 成績所屬學期 |
| 是否補修成績 | ✓ | ✓ | 必須填「是」或「否」 |
| 補修學年度 | ✓ | ✓ | 當是否補修成績=是時必填 |
| 補修學期 | ✓ | ✓ | 當是否補修成績=是時必填 |
| 重修學年度 | ✓ | ✓ | 當有重修成績時必填 |
| 重修學期 | ✓ | ✓ | 當有重修成績時必填 |
| 成績年級 | ✓ | - | 自動模式必填 |
| 取得學分 | ✓ | ✓ | 自動模式填「自動」，手動模式填「是」或「否」 |

### 3.4 補修成績匯入處理邏輯

#### 3.4.1 補修成績及格判斷（程式碼：572-583行）

```csharp
// 補修成績的 ScoreP（是否及格）判斷
// 使用「原始成績」與「修課及格標準」比較
if (decimal.TryParse(GetRowDataCellValue(row, "原始成績"), out retakeScoreValue))
{
    // 原始成績必須 >= 及格標準才算及格
    if (retakeScoreValue >= passingStandardForScoreP)
        ScoreP = "1";  // 及格
    else
        ScoreP = "0";  // 不及格
}
else
{
    ScoreP = "0";  // 無法解析原始成績時，預設為不及格
}
```

#### 3.4.2 補考成績處理（程式碼：586-615行）

- 補考成績必須在 0 到「修課及格標準」之間才有效
- 若補考成績超過及格標準或為負數，設為 "-1"（無效）
- 補考成績的及格判斷（reScoreP）：
  - 若補考成績無效，reScoreP = "-1"
  - 若補考成績 >= 及格標準，reScoreP = "1"（及格）
  - 否則 reScoreP = "0"（不及格）

#### 3.4.3 修課及格標準來源（2025-07-22 修正）

系統優先使用以下來源取得及格標準：

1. **優先**：現有成績資料的「修課及格標準」欄位
2. **其次**：若無現有成績資料，預設為 60 分

**不再使用**：匯入資料中的「修課及格標準」欄位

### 3.5 補修成績寫入學習歷程

#### 3.5.1 寫入時機

當「是否補修成績」= 是，且補修學年度、補修學期欄位有值時，系統會將補修成績寫入學習歷程。

#### 3.5.2 寫入目標

- **工作頁**：4.3 補修成績
- **學年度/學期**：使用「補修學年度」和「補修學期」欄位值

#### 3.5.3 寫入欄位對應（程式碼：706-732行）

| 學習歷程欄位 | 來源 | 說明 |
|------------|------|------|
| 學生系統編號 | StudentID | 學生ID |
| 身分證號 | IDNumber | 學生身分證號 |
| 出生年月日 | Birthday | 學生出生日期（民國年格式） |
| 學年度 | 學年度欄位 | 成績所屬學年度 |
| 學期 | 學期欄位 | 成績所屬學期 |
| 課程代碼 | 修課科目代碼 | 從現有成績資料讀取 |
| 科目名稱 | 科目欄位 | 科目名稱 |
| 科目級別 | 科目級別欄位 | 科目級別 |
| 成績年級 | 成績年級欄位 | 成績年級 |
| 學分數 | 學分數欄位 | 學分數 |
| 補修成績 | 原始成績欄位 | 補修的原始成績 |
| 補修及格 | ScoreP | 根據原始成績判斷（1=及格，0=不及格） |
| 補考成績 | reScore | 補考成績（-1=無效） |
| 補考及格 | reScoreP | 根據補考成績判斷（1=及格，0=不及格，-1=無效） |

#### 3.5.4 是否採計學分判斷（useCredit欄位）

系統根據以下規則判斷補修成績是否採計學分：

1. **抵免**：若「抵免」= 是，useCredit = "2"
2. **不採計**：若課程代碼符合特殊條件（第16碼="9"且第18碼="D"），useCredit = "3"
3. **一般採計**：預設 useCredit = "1"

### 3.6 匯入完成後續處理

#### 3.6.1 更新學期科目成績

匯入時會同步更新學期科目成績的以下欄位：

- 原始成績
- 補修學年度
- 補修學期
- 是否補修成績

#### 3.6.2 觸發事件

匯入完成後，系統會：

1. 呼叫 `EventHub.Instance.InvokScoreChanged` 通知成績變更
2. 呼叫 `FISCA.Features.Invoke("StudentLearningHistoryDetailContent")` 同步學習歷程

## 四、補修成績的計算處理

### 4.1 計算功能位置

**程式檔案**：`WearyDogComputer.cs`  
**相關功能**：計算學期科目成績

### 4.2 補修成績識別與分類（程式碼：758-768行）

```csharp
// 系統會將「是否補修成績」= 是的成績歸類到 makeupSubjectScoreMap
if (scoreinfo.Detail.GetAttribute("是否補修成績") == "是")
{
    if (makeupSubjectScoreMap.ContainsKey(studentSubjectKey))
    {
        makeupSubjectScoreMap[studentSubjectKey].Add(scoreinfo);

    else
```

- 補修成績會依據特定邏輯進行處理

```csharp
if (takeRepairScore == false)
```

## 五、補修成績在學習歷程的處理

### 5.1 學習歷程工作頁

補修成績主要記錄在學習歷程的以下工作頁：

| 工作頁編號 | 工作頁名稱 | 說明 |
|----------|----------|------|
| 4.3 | 補修成績 | 記錄補修課程的成績 |
| 4.2 | 學期成績 | 如果補修學年度/學期與畫面選擇不同，也會出現在此 |

### 5.2 補修成績產生邏輯（StudentLearningHistoryProcessor.cs）

#### 5.2.1 補修學年度/學期判斷（程式碼：899-906行）

```csharp
// 如果有勾是否補修成績，那補修學年度、學期和畫面上「不同」才會填入學年成績工作頁
// 相同的話會在補修成績工作頁
if (Utility.GetAttribute(elmScore, "是否補修成績") == "是")
{
    // 補修學年度、學期和畫面上選相同才會填入補修成績工作頁
    // 不同則填入學年成績工作頁（4.2）
    if (!(Utility.GetAttribute(elmScore, "補修學年度") == _SchoolYear.ToString() && 
          Utility.GetAttribute(elmScore, "補修學期") == _Semester.ToString()))
    {
        // 填入學年成績工作頁
    }
}
```

#### 5.2.2 處理流程

1. **判斷是否為補修成績**：檢查「是否補修成績」欄位
2. **比對學年度/學期**：
   - 若補修學年度/學期 = 畫面選擇的學年度/學期 → 寫入 4.3 補修成績工作頁
   - 若補修學年度/學期 ≠ 畫面選擇的學年度/學期 → 寫入 4.2 學期成績工作頁
3. **寫入資料**：依據上述判斷結果寫入對應工作頁

### 5.3 補修成績的資料查詢

#### 5.3.1 查詢SQL（程式碼：3047-3083行）

系統透過以下SQL查詢學習歷程中的補修成績：

```sql
SELECT 
    student_id,
    array_to_string(xpath('//Subject/@身分證號', subj_score_ele), '')::text AS 身分證號,
    array_to_string(xpath('//Subject/@課程代碼', subj_score_ele), '')::text AS 課程代碼,
    array_to_string(xpath('//Subject/@補修成績', subj_score_ele), '')::text AS 補修成績,
    array_to_string(xpath('//Subject/@補修及格', subj_score_ele), '')::text AS 補修及格,
    array_to_string(xpath('//Subject/@補考成績', subj_score_ele), '')::text AS 補考成績,
    array_to_string(xpath('//Subject/@補考及格', subj_score_ele), '')::text AS 補考及格,
    array_to_string(xpath('//Subject/@補修學年度', subj_score_ele), '')::text AS 補修學年度,
    array_to_string(xpath('//Subject/@補修學期', subj_score_ele), '')::text AS 補修學期,
    ...
FROM 
    student_learning_history
WHERE 
    serial_no = '4.3' 
    AND name = '補修成績'
ORDER BY 
    grade_year desc, 補修學期 desc, 補修學年度 desc
```

#### 5.3.2 補修成績與學期成績的比對（程式碼：293-358行）

系統會將補修成績與學期成績進行比對，補充補考成績資訊：

1. **取得補修資料**：從學習歷程 4.3 工作頁取得補修成績
2. **取得學期成績**：取得有補修資料的學期成績
3. **比對條件**：學生ID、科目名稱、科目級別
4. **補充資料**：將學期成績的補考成績（ReScore）補入補修記錄
5. **及格判斷**：根據補考成績與及格標準判斷補考是否及格（ReScoreP）

## 八、重要處理邏輯整理

### 8.1 補修成績及格判斷標準

| 成績類型 | 判斷依據 | 及格條件 | 備註 |
|---------|---------|---------|------|
| 補修成績（Score） | 原始成績 | 原始成績 >= 修課及格標準 | 2025-07-23 修正 |
| 補考成績（ReScore） | 補考成績 | 補考成績 >= 修課及格標準 | 且需在 0~及格標準範圍內 |

### 8.2 修課及格標準來源優先順序

1. **第一優先**：現有成績資料的「修課及格標準」欄位
2. **第二優先**：預設值 60 分

**不使用**：匯入資料中的「修課及格標準」欄位（2025-07-22 修正）

### 8.3 補修成績寫入學習歷程的時機

| 條件 | 寫入工作頁 | 說明 |
|------|----------|------|
| 是否補修成績 = 是<br>補修學年度 = 畫面學年度<br>補修學期 = 畫面學期 | 4.3 補修成績 | 補修當學期的成績 |
| 是否補修成績 = 是<br>補修學年度 ≠ 畫面學年度<br>或 補修學期 ≠ 畫面學期 | 4.2 學期成績 | 補修其他學期的成績 |
| 是否補修成績 = 否 | 4.2 學期成績 | 一般成績 |

### 8.4 補修成績在各項計算中的處理

| 計算項目 | 是否採計補修成績 | 說明 |
|---------|---------------|------|
| 分項成績計算 | 依成績計算規則設定 | 預設不採計 |
| 學年成績計算 | 依成績計算規則設定 | 預設不採計 |
| 學年調整成績 | 強制排除 | 2024/10/15 修正 |
| 畢業成績計算 | 依成績計算規則設定 | - |

## 十一、常見問題與注意事項

### 11.1 補修成績匯入失敗

**可能原因**：
1. 科目不存在於系統中（本功能僅允許更新成績，不允許新增科目）
2. 補修學年度/學期未填寫或格式錯誤
3. 是否補修成績欄位未填寫或填寫錯誤

**解決方式**：
1. 確認學生在該學期已有此科目成績
2. 檢查補修學年度/學期欄位格式（必須為數字）
3. 確認是否補修成績欄位填寫「是」或「否」

### 11.2 補修成績未出現在學習歷程

**可能原因**：
1. 補修學年度/學期與產生學習歷程時選擇的學年度/學期不符
2. 是否補修成績欄位未設為「是」

**解決方式**：
1. 檢查補修學年度/學期設定
2. 確認是否補修成績欄位值為「是」
3. 重新產生學習歷程

### 11.3 補修成績影響分項成績計算

**可能原因**：
成績計算規則中「補修成績」已勾選（採計）

**解決方式**：
若不希望補修成績納入計算，請至「成績計算規則」取消勾選「補修成績」

### 11.4 補修成績及格標準問題

**注意事項**：
- 系統優先使用現有成績資料的「修課及格標準」
- 匯入時的「修課及格標準」欄位不會被使用（2025-07-22 修正）
- 若無現有成績資料，預設使用 60 分

### 11.5 補修成績與重修成績的處理

**注意事項**：
- 補修成績和重修成績是不同的處理流程
- 補修成績使用「原始成績」進行及格判斷
- 重修成績使用「重修成績」進行及格判斷
- 兩者寫入不同的學習歷程工作頁（4.3 vs 5.2）
