# 新增「含不評分課程」調整記錄（1226）

## 變更摘要

實作「含不評分課程」checkbox 功能，允許使用者選擇是否在課程清單中顯示不評分課程。主要變更為：
1. 將 SQL 層級的 `not_included_in_calc='0'` 過濾移除，改為在 C# 程式碼中進行篩選
2. 新增 `chkNotIncludedInCalc` checkbox 控制項，預設未勾選（僅顯示列入計算課程）
3. 勾選後可顯示全部課程（包含不評分課程）

---

## 影響範圍

### 修改的檔案

1. **`DAO/CourseScoreBase.cs`**
   - 新增 `NotIncludedInCalc` 屬性（bool）：是否不列入成績計算
   - 新增 `NotIncludedInCalcRaw` 屬性（string）：DB 原始值（除錯用）

2. **`DAO/QueryData.cs`**
   - **`GetCourseScoreBaseByCourseSchoolYearSemester()` 方法**：
     - SQL SELECT 增加 `course.not_included_in_calc` 欄位
     - 移除 WHERE 條件中的 `and not_included_in_calc='0'`
     - 在組 `CourseScoreBase` 物件時，設定 `NotIncludedInCalcRaw` 與 `NotIncludedInCalc` 屬性
   - **`GetCousreTempleScoreTypeBySchoolYearSemester()` 方法**：
     - 移除 WHERE 條件中的 `AND not_included_in_calc='0'`

3. **`CourseScoreInputForm.cs`**
   - 在建構式中設定 `chkNotIncludedInCalc.Checked = false`（預設未勾選）
   - 綁定 `chkNotIncludedInCalc_CheckedChanged` 事件處理器
   - 在 `BindDataToListView()` 方法中加入篩選邏輯：
     - 未勾選時：只顯示 `NotIncludedInCalc == false` 的課程
     - 勾選時：顯示全部課程
     - 與既有的 `chkNotHasScore` 篩選可同時運作

---

## 規則定案

### `not_included_in_calc` 欄位判斷規則（定案）

- **只有 `'0'` 才視為 false（列入計算）**
- **其餘一律視為 true（不列入計算 / 不評分）**

實作方式：
```csharp
string raw = dr[2] == DBNull.Value ? null : dr[2].ToString();
csb.NotIncludedInCalcRaw = raw;
csb.NotIncludedInCalc = raw != "0";  // 只有 "0" 才是 false，其他一律 true
```

## 風險與回復方式

### 潛在風險

1. **資料量增加**：移除 SQL 過濾後，查詢會載入更多課程資料（包含不評分課程）
   - **影響**：記憶體使用量可能略增，但通常影響不大
   - **緩解**：已在 UI 層進行篩選，預設仍只顯示列入計算課程

2. **效能影響**：`GetCousreTempleScoreTypeBySchoolYearSemester()` 移除過濾後，可能查詢到更多模板資料
   - **影響**：查詢時間可能略增
   - **緩解**：僅在勾選「含不評分課程」時才會顯示這些資料，且資料量通常不大

### 回復方式

若需要回滾此變更，可執行以下步驟：

1. **還原 `QueryData.cs`**：
   - 在 `GetCourseScoreBaseByCourseSchoolYearSemester()` 的 SQL 中：
     - 移除 SELECT 中的 `course.not_included_in_calc`
     - 恢復 WHERE 中的 `and not_included_in_calc='0'`
     - 移除設定 `NotIncludedInCalc` 與 `NotIncludedInCalcRaw` 的程式碼
   - 在 `GetCousreTempleScoreTypeBySchoolYearSemester()` 的 SQL 中：
     - 恢復 WHERE 中的 `AND not_included_in_calc='0'`

2. **還原 `CourseScoreBase.cs`**：
   - 移除 `NotIncludedInCalc` 與 `NotIncludedInCalcRaw` 屬性

3. **還原 `CourseScoreInputForm.cs`**：
   - 移除建構式中設定 checkbox 預設值與事件綁定的程式碼
   - 移除 `chkNotIncludedInCalc_CheckedChanged` 事件處理器
   - 移除 `BindDataToListView()` 中的篩選邏輯
