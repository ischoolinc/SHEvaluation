## 目標
調整「匯入重補修成績」的必填規則。

新的必填規則需要同時符合：

1. Excel 必須存在指定必填欄位。
2. 必填欄位必須被選入匯入欄位。
3. 必填欄位的每一筆資料不可空白。
4. 欄位內容仍需依既有格式規則驗證。

修改完成後，請將調整內容記錄於：

匯入重補修成績調整1006.md


## 修改程式
ImportMakeupRetakeScore.cs


## 一、目前問題

目前已經透過：

wizard.RequiredFields.AddRange(...)

設定必填欄位。

目前 RequiredFields 包含：

- 科目
- 科目級別
- 學年度
- 學期
- 成績年級
- 是否補修成績
- 補修學年度
- 補修學期
- 重修學年度
- 重修學期
- 學分數
- 分項類別
- 必選修
- 校部訂
- 原始成績
- 重修成績
- 取得學分

但是目前 ValidateRow 的驗證方式是：

foreach (string field in e.SelectFields)

因此只有「已經存在且被選為匯入欄位」的欄位才會進行驗證。

如果 Excel 完全沒有某個必填欄位，例如：

重修成績

則該欄位不會出現在 e.SelectFields，
因此：

case "重修成績"

完全不會被執行。

結果會造成：

Excel 缺少必填欄位，但系統沒有正確檢查出來。


## 二、調整必填欄位存在檢查

請新增一組統一的必填欄位清單，例如：

string[] requiredImportFields = new string[]
{
    "科目",
    "科目級別",
    "學年度",
    "學期",
    "成績年級",
    "是否補修成績",
    "補修學年度",
    "補修學期",
    "重修學年度",
    "重修學期",
    "學分數",
    "分項類別",
    "必選修",
    "校部訂",
    "原始成績",
    "重修成績",
    "取得學分"
};

此清單應與 wizard.RequiredFields 保持一致。


## 三、檢查 Excel 是否存在所有必填欄位

在進入每列內容驗證前，先確認所有 requiredImportFields 都存在於此次匯入欄位。

概念如下：

foreach (string requiredField in requiredImportFields)
{
    if (!e.SelectFields.Contains(requiredField))
    {
        // 缺少必填欄位
    }
}

如果必填欄位不存在：

- 必須阻止匯入。
- 顯示明確錯誤訊息。
- 錯誤訊息需要指出缺少哪一個欄位。

例如：

缺少必填欄位：重修成績

或：

Excel 缺少必填欄位「重修成績」。


## 四、避免只依賴 ValidateRow

這是「整份 Excel 的欄位結構錯誤」，
不是單一資料列的錯誤。

因此優先評估是否可以在：

ValidateStart

或 Import Wizard 可取得匯入欄位清單的較前段事件

進行一次性驗證。

目標：

Excel 若缺少：

- 學分數
- 分項類別
- 必選修
- 校部訂
- 原始成績
- 重修成績
- 取得學分

等必填欄位，

應在正式逐筆驗證前直接提示，
不要等到每一列都重複報相同錯誤。


## 五、如果框架限制無法在 ValidateStart 取得欄位

若目前 SmartSchool Importer API 在 ValidateStart 無法取得 Excel 欄位清單，

則可暫時在 ValidateRow 中進行檢查。

但請注意：

不要每一筆資料都重複加入同一個「缺少欄位」錯誤。

請設計防重複機制，例如：

- 使用 bool
- HashSet<string>
- 或其他適合方式

確保同一個缺少欄位問題不要重複累加大量訊息。


## 六、保留原本 RequiredFields

## 八、必填驗證層次

請將驗證概念整理為三層：


### 第一層：Excel 欄位存在

確認 Excel 有：

requiredImportFields

所有欄位。

沒有：

直接報「缺少必填欄位」。


### 第二層：欄位被選入匯入

透過：

wizard.RequiredFields

確保必填欄位不能被使用者取消。


### 第三層：每列資料內容

透過：

ValidateRow

檢查：

- 空白
- 數值格式
- 是/否
- 自動
- 必修/選修
- 校訂/部訂
- 分項類別

等資料規則。


## 九、注意事項

本次只調整必填規則。

請勿修改：

1. 重修成績擇優邏輯。
2. 補修成績處理邏輯。
3. 取得學分自動計算邏輯。
4. 修課及格標準判斷。
5. 補修成績 4.3 名冊寫入。
6. 重修成績 5.2 名冊寫入。
7. 學期科目成績更新流程。
8. 原本其他非必填欄位的驗證方式。
